# protein-dna-binding-feature-importance-analysis

## Summary

Ranks multi-view protein features and extracts the optimal discriminating subset for DNA-binding protein (DBP) prediction using SVM-RFE+CBR, as in iDBP-DEP, which reduces the 3240-dimension DDE/PSSM-DBT/PSSM-DWT/NMBAC vector to a 424-feature optimum.

## When to use

Use when a concatenated multi-view protein feature vector (e.g. 3240-D DDE, PSSM-DBT, PSSM-DWT, NMBAC) contains noisy/redundant features and you need ranked feature importance plus an optimal subset before SVM classification.

## When NOT to use

- Input is already a small, non-redundant feature table where SVM-RFE+CBR ranking would add cost without benefit
- The task is raw sequence annotation rather than feature-space analysis — feature extraction (DDE, PSSM-DBT, PSSM-DWT, NMBAC) must happen first
- Only the independent-test dataset (PDB186) is available without a training set to drive the recursive feature elimination

## Inputs

- Concatenated multi-view feature matrices (.mat) for PDB1075, PDB594 or PDB186: DDE, PSSM-DBT, PSSM-DWT, NMBAC descriptors
- PSSM profiles generated by PSI-BLAST search against nr for each protein sequence
- Class labels for benchmark datasets (PDB1075: 525 DBPs / 550 non-DBPs)

## Outputs

- Ranked feature list (all 3240 features ordered by SVM-RFE+CBR weight)
- Jackknife accuracy curve over subset sizes (top-10 to top-3240, step 2)
- Optimal feature subset (424 dimensions: 51 DDE, 202 PSSM-DBT, 129 PSSM-DWT, 42 NMBAC) with accuracy and MCC

## How to apply

Load the deposited .mat workspace feature files (e.g. PDB1075_workspace: DDE_workspace.mat, PSSM_DBT_workspace.mat, PSSM_DWT_workspace.mat, feature_NMBAC_workspace.mat) and concatenate them into the 3240-dimension vector. Rank all features with SVM-RFE+CBR (v1.3), computing SVM feature weights with LIBSVM 3.21 under an RBF kernel with grid-search-optimized C=1 and gamma=0.03125, iteratively deleting the lowest-weight features while applying Correlation Bias Reduction to curb redundancy bias. At each elimination step, retrain the SVM on the remaining features and record Jackknife cross-validation accuracy until the feature space is empty. Sweep ranked subsets from top-10 to top-3240 in steps of 2 and select the size with highest accuracy; for PDB1075 (525 DBPs, 550 non-DBPs) the optimum is 424 dimensions (51 DDE, 202 PSSM-DBT, 129 PSSM-DWT, 42 NMBAC) at ~88.00% Jackknife accuracy (MCC 0.760). Feed the selected subset into the SVM classifier and record ranked indices and the accuracy curve.

## Related tools

- **LIBSVM** (Implements the RBF-kernel SVM (C=1, gamma=0.03125) whose feature weights drive SVM-RFE ranking and which trains the final model on the selected subset) — https://githup.com/Zll-codeside/iDBP-DEP
- **SVM-RFE-CBR-v1.3** (Performs recursive feature elimination with correlation bias reduction to rank features and obtain optimal subsets in each protein feature space) — https://githup.com/Zll-codeside/iDBP-DEP

## Evaluation signals

- Optimal subset size equals 424 dimensions for PDB1075 with Jackknife accuracy at or near 88.00% (MCC 0.760)
- Per-descriptor composition of the selected subset matches 51 DDE, 202 PSSM-DBT, 129 PSSM-DWT, 42 NMBAC
- Accuracy curve is monotone-evaluable over the top-10 to top-3240 sweep with step 2 and terminates with the empty feature space
- SVM parameters recovered from grid search are C=1 and gamma=0.03125 as reported
- Ranked indices and selected features persist to a feature-selection output file for reproducibility

## Limitations

- No version numbers stated for LIBSVM in the article (repo code shows libsvm-321) and no accession IDs or provenance given for benchmark datasets PDB1075, PDB594, PDB186
- Optimal subset size and accuracy are dataset-specific (PDB1075 optimum 424); PDB594 and PDB186 may yield different optima
- Jackknife test is computationally heavy over the full elimination sweep on 1075 proteins
