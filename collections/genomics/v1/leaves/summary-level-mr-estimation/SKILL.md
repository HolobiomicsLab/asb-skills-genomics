# summary-level-mr-estimation

## Summary

Fit competing summary-data Mendelian Randomization estimators (e.g., IVW, MR-Egger) with the MendelianRandomization R package on GWAS summary statistics (bx, bxse, by, byse) generated by simmrd's generate_summary(), and compare the estimated causal effects against the true effects (theta).

## When to use

Use when you have IV–exposure associations (bx, bxse) and IV–outcome associations (by, byse) from GWAS summary data — e.g., a simmrd generate_summary() replicate — and need causal effect estimates from one or more summary-level MR estimators.

## When NOT to use

- You only have individual-level genotype/phenotype data (from generate_individual()) and want two-sample summary MR — construct summary statistics first or use individual-level MR methods instead
- You need to simulate or generate the GWAS summary data itself — that is the role of simmrd's set_params()/generate_summary(), not of the MR estimation step
- You require estimators (e.g., LD-aware or robust variance methods) not implemented in the MendelianRandomization package

## Inputs

- simmrd generate_summary() output list containing bx (m x p IV–exposure association matrix), bxse (standard errors), by (m x 1 IV–outcome association vector), and byse (standard errors)
- True causal effects vector theta from simmrd (for context/comparison)
- Optional: LDMatrix / LDhatMatrix and RhoME from the simmrd replicate if the estimator requires correlated IVs or measurement-error correlation

## Outputs

- mr_estimates.csv — structured record with estimator name and finite numeric causal effect estimate(s) per estimator run
- Causal effect estimate(s) per MR estimator (e.g., IVW, MR-Egger) comparable against simmrd's theta

## How to apply

Load the simulated summary-data replicate emitted by simmrd::generate_summary(), which returns an m x p matrix of IV–exposure associations (bx) with standard errors (bxse), an m x 1 vector of IV–outcome associations (by) with standard errors (byse), and the true causal effects (theta). Construct an MR input object in the MendelianRandomization R package from these quantities (mr_input(bx, bxse, by, byse)) and run at least one summary-data estimator such as IVW or MR-Egger. Extract the causal effect estimate(s) and compare them against theta, which simmrd returns as ground truth for the replicate. Write the estimator name and causal effect estimate(s) to mr_estimates.csv as a structured record per estimator. For multivariable settings (multiple exposures), bx is m x p and theta is a vector of p true effects, so each estimator should yield one estimate per exposure.

- **simmrd** (Generates the simulated GWAS summary-data replicate (bx, bxse, by, byse, theta) via generate_summary() that serves as the input to the MR estimators) — https://github.com/noahlorinczcomi/simmrd
- **simmrd (R package)** (R interface for set_params()/generate_summary() to build the parameter list and produce the summary statistics consumed by this skill) — https://github.com/noahlorinczcomi/simmrd
- **MendelianRandomization R package** (Constructs the MR input object from bx/bxse/by/byse and runs the summary-data estimators (IVW, MR-Egger) that produce the causal effect estimates)

## Examples

```
library(simmrd); params <- set_params(number_of_exposures=3); sim <- generate_summary(params); mr <- MendelianRandomization::mr_input(bx=sim$bx, bxse=sim$bxse, by=sim$by, byse=sim$byse); fit <- MendelianRandomization::mr_ivw(mr)
```

## Evaluation signals

- mr_estimates.csv exists and is valid CSV
- mr_estimates.csv contains a finite numeric causal effect estimate for each estimator run
- Estimates are directionally consistent with simmrd's true causal effects (theta), e.g., IVW on a valid-IV replicate should be close to theta
- The number of estimates per estimator matches the number of exposures p (one per exposure for MVMR)
- The MR input object was constructed without errors from bx/bxse/by/byse, confirming the simmrd replicate integrates correctly with the MendelianRandomization package

## Limitations

- Both generate_summary() and generate_individual() generate simulated data for a single simulation replicate — estimates reflect one replicate, not Monte Carlo averaged performance
- MR estimators can break down under weak instruments (weak IV bias generally becomes more severe as more IVs are used) and horizontal pleiotropy (UHP/CHP IVs are flagged by simmrd as 'UHP' or 'CHP' in IVtype)
- Winner's curse (simtype 'winners' with IV_Pvalue_threshold 5e-8) and GWAS sample overlap (prop_gwas_overlap_Xs_and_Y) can bias the summary associations fed to the estimators
- The MendelianRandomization package integrates with standardized summary data; unstandardized versions (bx_unstd/by_unstd) are provided separately by simmrd
