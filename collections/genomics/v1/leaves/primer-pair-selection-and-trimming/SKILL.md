# primer-pair-selection-and-trimming

## Summary

A PacBio Iso-Seq subread preprocessing skill in which LIMA selects CCS reads containing valid pairs of primers and removes the primer sequences, followed by chimera detection, producing clean full-length non-chimeric (FLNC) reads for downstream polyA trimming.

## When to use

Use when PacBio subread BAM files must be converted into primer-trimmed, chimeric-free FLNC reads before polyA trimming, alignment, or isoform annotation in an Iso-Seq workflow.

## When NOT to use

- Input is already FLNC reads with primers removed and chimeras discarded — re-running LIMA would find no primer pairs to select.
- Data is short-read or not PacBio single-molecule sequencing data — the ccs/LIMA/isoseq3 refine chain is specific to PacBio Iso-Seq libraries.
- The goal is demultiplexing barcodes from pooled samples without Iso-Seq library structure, where primer-pair selection does not apply as the primary operation.

## Inputs

- PacBio subread BAM files
- Circular Consensus Sequence (CCS) reads generated by the ccs tool
- Primer sequences/pairs used in the Iso-Seq library preparation

## Outputs

- Primer-trimmed CCS reads with valid primer pairs (LIMA output)
- FLNC BAM reads with chimeras discarded (isoseq3 refine output)
- FLNC FASTA files (bamtools convert output)
- Chunked polyA-tail-free FLNC FASTA files (gstama_polyacleanup output)

## How to apply

First run PacBio ccs on the input subread BAM files to generate Circular Consensus Sequence (CCS) reads. Then run LIMA (from the PacificBiosciences barcoding repo) on the CCS output: it selects only the sequences containing valid pairs of primers and removes the primer sequences from them. Next run isoseq3 refine (from the IsoSeq repo) on the primer-trimmed reads to detect and discard chimeric reads, yielding the FLNC BAM output. Convert the FLNC reads with BAMTools convert from BAM into FASTA format, then run TAMA cleanup (gstama_polyacleanup) to detect and trim polyA tails, writing chunked polyA-tail-free FLNC FASTA files. The rationale is that only reads bracketed by valid primer pairs represent full-length cDNA molecules, and chimeras must be removed before they contaminate downstream clustering and annotation.

## Evaluation signals

- Confirm the final chunked FASTA artifacts exist and are in FASTA format.
- Confirm the FASTA contains FLNC reads whose primer pairs are valid (i.e., every retained read matched a primer pair and primers are absent from sequences).
- Confirm chimeric sequences were detected and discarded during the isoseq3 refine step.
- Confirm polyA tails were removed per the pipeline's TAMA cleanup (gstama_polyacleanup) step.
- Confirm the workflow order held: ccs -> LIMA -> isoseq3 refine -> bamtools convert -> gstama_polyacleanup.

## Limitations

- No software version numbers are recorded for the tools/modules in this pipeline's changelog, creating a reproducibility gap for pinning tool versions.
- The skill assumes Iso-Seq library structure with known primer pairs; reads without valid primer pairs are discarded rather than recovered.
- A separate downstream step (TAMA cleanup) is required for polyA tail removal — LIMA and isoseq3 refine alone do not produce polyA-free FLNC reads.
