# isoform-exon-structure-counting

## Summary

Count exon features per transcript from an annotated GTF (e.g. StringTie assembly reconciled by annotate_my_genomes) to characterize isoform structures of a target gene locus, such as the >105-exon chicken SSPO gene, and validate them against expected exon counts, protein lengths, and BLAST identity.

## When to use

Use when a genome-guided transcriptome assembly (StringTie GTF from merged PacBio+Illumina BAMs) must be characterized per-isoform at a specific locus by parsing exon features and counting exons per transcript ID.

## When NOT to use

- Input is raw reads or an unannotated StringTie GTF without coding/noncoding reconciliation — run annotate-my-genomes.nf first to obtain final_annotated.gtf
- The organism lacks an assembled genome and an NCBI GTF annotation, since the pipeline requires both as inputs
- The goal is de novo isoform discovery without a reference genome; this skill is genome-guided only

## Inputs

- final_annotated.gtf from annotate_my_genomes (reconciled StringTie assembly, gene_id/transcript_id fields)
- galGal6 reference genome FASTA and NCBI RefSeq GTF used as -r/-g inputs
- cds.fa and prot.fa protein/CDS predictions from the pipeline
- Reference protein sequence (e.g. SSPO protein deduced from AJ866919)

## Outputs

- Per-isoform exon count table (e.g. sspo_isoform_validation.csv) with transcript ID, exon count, coding/lncRNA class, protein length, and BLAST identity
- Set of validated isoform exon structures (expected: 106/106/105/17/25 exons for chicken SSPO)
- blastp report of the longest isoform protein against the reference protein

## How to apply

Load the annotate_my_genomes output final_annotated.gtf (generated by running ./annotate-my-genomes -a stringtie.gtf -r galGal6.gtf -g galGal6.fa -c gawn_config.sh -t 20 -o output1) and filter transcript records to the target locus (e.g. SSPO/SCO-spondin) using the gene_id field and genomic coordinate overlap. For each transcript, parse exon features from the GTF and count exons, confirming the expected isoform set — for chicken SSPO this is two 106-exon isoforms plus 105-, 17-, and 25-exon isoforms (five coding isoforms in total). Extract CDS and protein sequences from the pipeline outputs cds.fa and prot.fa and verify that the longest isoform encodes the expected protein (transcript 1: 5270 aa). Confirm coding vs lncRNA classification via the pipeline's coding/noncoding annotation (FEELnc trained on 'NM_' coding RNAs, TransDecoder for unclassified transcripts). Optionally blastp the longest protein (-max_hsps 1 -max_target_seqs 1) against the reference (e.g. AJ866919-derived protein) and compile exon counts, protein lengths, and identity per isoform into a CSV such as sspo_isoform_validation.csv.

## Examples

```

```

## Evaluation signals

- Exon-count table reports the expected isoform set: for chicken SSPO, five coding isoforms with exon counts 106/106/105/17/25
- Longest isoform (transcript 1) protein length in prot.fa equals 5270 amino acids
- blastp (-max_hsps 1 -max_target_seqs 1) returns 98.88% identity to the AJ866919-derived chicken SSPO protein
- All five isoforms are classified as protein-coding rather than lncRNA in the reconciled annotation
- Filtered transcripts overlap the SSPO/SCO-spondin locus coordinates and carry consistent gene_id values in final_annotated.gtf

## Limitations

- Protein products of smaller SSPO isoforms (e.g. 89-exon and 25-exon) remain to be validated; lower molecular weight bands (200 to 50 kD) were only inferred to correspond to smaller isoforms
- The approach requires an assembled genome and an NCBI annotation in GTF format; no result is reported for organisms lacking these
- Recovery of very long isoforms (>105 exons) depends on merged PacBio+Illumina depth; Illumina-only or PacBio-only assemblies may miss exons
