# gene-fusion-detection-long-read

## Summary

Detect gene fusions from full-length Iso-seq (PacBio HiFi) transcripts using the TAGET fusion module, which combines Minimap2 and HISAT2 alignment evidence with gene annotation to call fusion-supported reads, and benchmark calls against simulated ground truth or comparator callers such as SQANTI and JAFFAL.

## When to use

Use when you have full-length PacBio Iso-seq FASTA/CCS reads and want to identify gene fusions, novel fusion isoforms, or benchmark a long-read fusion caller against SQANTI/JAFFAL.

## When NOT to use

- Input reads are short RNA-seq reads rather than full-length Iso-seq CCS transcripts — TAGET's fusion module requires long-read alignment beds from Minimap2/HISAT2
- You need only transcript annotation or expression quantification without fusion calling — use TAGET's TransAnnot/TransAnnotMerge components instead
- No reference genome and Ensembl GTF annotation (hg38.fa, hg38.gtf) are available, since the fusion module requires hg38.gtf and annotated stat inputs

## Inputs

- Full-length transcript FASTA from PacBio Iso-seq (CCS reads)
- Reference genome FASTA (hg38.fa)
- Ensembl GTF annotation (e.g., hg38.ensembl.gtf and its pickle generated by gtf_db_make.py)
- Minimap2 alignment bed ({sample_id}.fa.minimap2.bed)
- HISAT2 alignment bed ({sample_id}.fa.hisat2.bed)
- TAGET annotation stat file ({sample_id}.fa.anno.tmp.stat)

## Outputs

- Predicted gene fusion calls per sample (written to the output directory)
- Fusion candidate reads/transcripts classified as 'FUSION' in {sample_id}.annot.stat
- Benchmark metrics (sensitivity, specificity, F-score) when run against simulated ground truth (e.g., fusion_benchmark_metrics.csv)

## How to apply

First align the full-length transcript FASTA to a reference genome (e.g., hg38.fa with Ensembl GTF annotation) using both Minimap2 and HISAT2, processing results with samtools into per-sample bed files ({sample_id}.fa.minimap2.bed and {sample_id}.fa.hisat2.bed) and a TAGET annotation stat file ({sample_id}.fa.anno.tmp.stat). Then run the TAGET fusion script with these beds, the stat file, the hg38.gtf, and the original FASTA; the module leverages TAGET's precise splice-junction calls and reads classified as 'FUSION' in the {sample_id}.annot.stat classification. For evaluation, score predicted fusions against simulated ground truth (e.g., 300 gene fusions per dataset with random partner genes, breakpoints, indels/SNPs, and 1-5 supporting transcripts per fusion on a GM12878 background) and compute sensitivity, specificity, and F-score, optionally comparing to SQANTI and JAFFAL as independent callers.

## Examples

```
Rscript TAGET_fusion_2-3_ajust.r -j Jin_fusion_select.py -e STAT_select.py -l ${i}.fa.minimap2.bed -s ${i}.fa.hisat2.bed -a ${i}.fa.anno.tmp.stat -t hg38.gtf -f ${i}.fa -n ${i} -o ./output
```

## Evaluation signals

- Score predicted fusions against simulated ground truth (300 fusions/dataset) and compute sensitivity, specificity, and F-score; TAGET should achieve the best sensitivity and F-score vs SQANTI and JAFFAL on simulated Iso-seq datasets
- Reads supporting fusions should appear with Classification 'FUSION' in {sample_id}.annot.stat
- Required inputs exist before fusion calling: {sample_id}.fa.minimap2.bed, {sample_id}.fa.hisat2.bed, {sample_id}.fa.anno.tmp.stat, and hg38.gtf
- Around 86% of gene fusion candidates can be experimentally validated per the article's validation of novel transcripts and fusions

## Limitations

- On simulated Iso-seq data, sensitivity/F-score advantages are relative — SQANTI and JAFFAL remain valid comparators and performance depends on expression level of simulated fusions
- TAGET's alignment/annotation step relies on filtering low-quality CCS read clusters (clusters with only one CCS read, ~80% of reads filtered), which may discard reads from true expressed isoforms
- Fusion detection requires both HISAT2 and Minimap2 alignments and a matching GTF annotation; missing or mismatched genome builds will break the workflow
