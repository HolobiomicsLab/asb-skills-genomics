# cosine-similarity-signature-matching

## Summary

Compares de novo-extracted mutational signatures (e.g. RNMF denovoNMF SBS and ID signatures from the ESCC WGS508 cohort) against reference signatures such as COSMIC Mutational Signatures v2.0/v3.2 using cosine similarity, with a similarity threshold of 0.9 to declare a match.

## When to use

Use when de novo NMF-extracted mutational signatures (SBS, DBS, or ID count-matrix based) need to be assigned COSMIC identity, or when validating that an extraction run reproduced reported signature counts.

## When NOT to use

- When the goal is to quantify sample-level exposure to a known signature from user-defined P — use RNMF's InverseNMF instead of de novo cosine matching
- When input is raw somatic mutation calls (MAF/VCF) that have not yet been converted to a mutation-type count matrix via SigsInput
- When signatures come from a data type or genome build incompatible with the reference set used to build the comparison vectors

## Inputs

- Extracted mutational signature matrix P (signatures x 96 SBS mutation-type channels, or ID channels) from denovoNMF
- Reference signature vectors from COSMIC Mutational Signatures (v3.2 - March 2021 or v2.0 - March 2015)
- Count/information matrix of mutation types (SBS, DBS, ID) generated by RNMF SigsInput from MAF or VCF somatic mutation data

## Outputs

- Cosine similarity values between each de novo signature and each COSMIC reference signature
- Match assignments labeling de novo signatures (e.g. SBS1-SBS12) by their best COSMIC counterpart at threshold 0.9
- List of unmatched (novel) signatures, e.g. 'New'

## How to apply

After extracting K mutational signatures with RNMF's denovoNMF 5-step framework (random P/S initialization, Dirichlet-distribution resampling over 20,000 iterations, k-means re-optimization with >=5 repeats, multiplicative update rules up to 100,000 iterations, and >=20 repetitions to build a solution space), treat each extracted signature as a vector over mutation types (96 SBS channels or ID channels). Compute the cosine similarity between each extracted signature vector A and each reference COSMIC signature vector B; in this paper the threshold is set to 0.9, so an extracted signature is considered matched to a COSMIC signature only when cosine similarity reaches 0.9. Signatures failing the threshold (e.g. the 'New' signature reported in the ESCC 1073-sample analysis) are retained as potentially novel. Apply this comparison separately for SBS and ID signature sets, and use the matching results both to rename de novo signatures (SBS1 through SBS12 in the WGS508 cohort) and as a validation criterion for the denovoNMF extraction.

```

```

## Evaluation signals

- Matched signatures reach the cosine similarity threshold of 0.9 against their COSMIC counterparts
- The number of stable extracted signatures matches reported counts (12 SBS and 9 ID signatures in the WGS508 ESCC cohort)
- SBS signatures reproduce the expected COSMIC-named set, e.g. SBS3, SBS16, SBS18, New, SBS33, SBS13, SBS2, SBS5, SBS1, SBS17b, SBS22, SBS15 in the ESCC exon analysis
- Signatures with cosine similarity below 0.9 remain unmatched and are reported as novel rather than force-labeled

## Limitations

- Framework spends more time on de novo extraction than previously published software due to the re-updated initial value and build-a-solution-space processes before matching can occur
- Inconsistent sequencing background of pooled data (WGS vs exon sequencing) means only coding regions were uniformly analyzed, affecting signature quality before matching
- The relatively small number of individuals studied limits model learning, which can affect the stability of extracted signatures being matched
