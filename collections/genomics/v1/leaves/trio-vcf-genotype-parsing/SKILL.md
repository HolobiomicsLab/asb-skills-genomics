# trio-vcf-genotype-parsing

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Parses per-caller trio VCF files from the GIAB Ashkenazi Trio (HG002/HG003/HG004) ONT sup-datasets, extracts biallelic SNV genotypes, and computes the Mendelian Consistency Rate (MCR) to benchmark SNV callers such as miniSNV, Clair3, and Longshot on inheritance consistency.

## When to use

Use when multiple SNV callers' trio VCFs (child and parents, e.g. HG002/HG003/HG004) are available and you need to compare caller quality via Mendelian Consistency Rate rather than truth-set F1 alone.

## When NOT to use

- Input is raw nanopore FASTQ/BAM rather than called variant VCFs — variant calling must happen first (e.g. via miniSNV's chr_chunk_task.py pipeline)
- VCFs contain only indels, structural variants, or multiallelic sites — the workflow extracts biallelic SNV genotypes only
- Samples are not a parent–child trio (no parental genotypes to check inheritance against)

## Inputs

- Per-caller sup-dataset trio VCF files for HG002, HG003, HG004 (from miniSNV, Clair3, Longshot)
- Trio pedigree relationship mapping (child HG002; parents HG003, HG004)

## Outputs

- mcr_table.csv with one Mendelian Consistency Rate value per SNV caller
- Per-child-SNV Mendelian-consistent/inconsistent classifications per caller

## How to apply

Load the per-caller sup-dataset trio VCF files for HG002, HG003, and HG004 generated by miniSNV, Clair3, and Longshot. Parse each VCF to extract biallelic SNV genotypes (0/0, 0/1, 1/1) for all three trio members per caller. For each child SNV, apply Mendelian inheritance rules against the two parental genotypes to classify it as Mendelian-consistent or not. Compute MCR per caller as the fraction of child SNVs consistent with the parental genotypes, and write the per-caller values to mcr_table.csv. Rationale: the trio benchmark context is ONT R10.4.1 kit v14 sup-datasets (~200 Gbases/sample), where miniSNV and Longshot achieve MCRs about 3 percentage points higher than Clair3.

## Related tools

- **miniSNV** (Source of the trio sup-dataset VCF genotypes being evaluated for Mendelian consistency; reported as the top performer on HG002/HG003/HG004 sup-datasets) — https://github.com/CuiMiao-HIT/miniSNV
- **Clair3** (Comparison caller whose trio VCF genotypes yield the lower MCR baseline (~3 percentage points below miniSNV and Longshot))
- **Longshot** (Diploid SNV calling method whose trio VCF genotypes are parsed alongside miniSNV's and match its high MCR)

## Evaluation signals

- Regenerated mcr_table.csv shows miniSNV and Longshot MCRs exceeding Clair3's by roughly 3 percentage points
- Each caller's MCR is a fraction in [0, 1] computed over the same set of child biallelic SNVs across callers
- Output table contains exactly one MCR row per caller (miniSNV, Clair3, Longshot)
- Result is consistent with the reported trio benchmark where miniSNV achieved the highest metrics on HG002, HG003, and HG004 sup-datasets (F1-score and recall > 99.7%)

## Limitations

- Only biallelic SNV genotypes (0/0, 0/1, 1/1) are considered; multiallelic sites and indels are excluded from the MCR
- MCR depends on the upstream caller VCFs (task_001 outputs from ONT kit v14 / R10.4.1 sup basecalled data); caller-specific filtering (e.g. miniSNV's haplotype-aware filtering of 1/1 preGT calls) shapes the genotype set
- Mendelian consistency is not a truth-set metric — a caller can be Mendelian-consistent yet wrong at a site if the inheritance error is shared
