# synthetic-read-benchmark-validation

## Summary

Benchmark a long-read consensus computation by quantifying per-base error reduction between raw error-prone reads and POA-derived consensus sequences on simulated third-generation sequencing data, reproducing the ~77% (ONT) and ~88% (PB) reduction reported for TRiCoLOR's REFER module.

## When to use

Use when validating a consensus/variant-calling pipeline on simulated ONT or PacBio reads, or when reproducing the SPOA partial-order-alignment error reduction of ~77% (ONT) and ~88% (PB) reported in Supplementary Note S3 / Fig. S2.

## When NOT to use

- Input consists of real (non-simulated) long reads where the ground-truth per-base error rate is not known, making the raw-vs-consensus reduction denominator unreliable
- The goal is TR discovery/genotyping itself (use TRiCoLOR end-to-end) rather than validating the consensus step's error reduction

## Inputs

- VISOR-simulated ONT FASTQ reads (mean length 8,000 bp; error profile substitution:insertion:deletion ~45:25:30)
- VISOR-simulated PacBio FASTQ reads (error profile ~15:50:35)
- Haplotype-specific consensus BAM files generated by TRiCoLOR REFER (SPOA POA consensus + minimap2 realignment)
- Reference genome FASTA (e.g., GRCh38)

## Outputs

- consensus_error_reduction.csv with columns: technology, raw error rate, consensus error rate, reduction percentage, reported reference value
- Per-base error-rate estimates (substitutions, insertions, deletions per aligned base) for raw and consensus datasets

## How to apply

Simulate or load haplotype-specific long reads (e.g., VISOR-simulated ONT reads of mean length 8,000 bp with substitution:insertion:deletion profile ~45:25:30, and PB reads with ~15:50:35) plus the haplotype-specific consensus BAMs produced by TRiCoLOR REFER via SPOA partial order alignment and minimap2 realignment. Align raw reads and consensus sequences to the same GRCh38-style reference with minimap2 and compute per-base error rates (substitutions, insertions, deletions per aligned base) using edit-distance-based comparison. Compute reduction percentage as (raw error rate − consensus error rate) / raw error rate × 100, separately for ONT and PB. Validate against the reported ~77% (ONT) and ~88% (PB) within a tolerance band (e.g., ±5 percentage points).

## Examples

```
minimap2 -ax map-ont GRCh38.fa visor_simulated_ont.fq > raw_aln.sam; minimap2 -ax map-ont GRCh38.fa tricolor_refer_consensus.fq > consensus_aln.sam
```

## Evaluation signals

- Computed error reduction falls within ±5 percentage points of ~77% for ONT and ~88% for PB
- consensus_error_reduction.csv exists with the required columns: technology, raw error rate, consensus error rate, reduction percentage, reported reference value
- Raw read error profiles match the expected simulation parameters (ONT ~45:25:30 substitution:insertion:deletion; PB ~15:50:35)
- Consensus error rate is strictly lower than raw error rate for both platforms
- minimap2 alignments of raw and consensus reads are computed against the identical reference build so error rates are comparable

## Limitations

- TRiCoLOR cannot identify repeats in unassembled regions of the genome (e.g., human centromeres and telomeres)
- No support for polyploid species or haploid chromosomes (e.g., human Y chromosome)
- Supplementary figures/notes (e.g., Supplementary Fig. S2, Note S3) referenced but content not included in main text; exact benchmark parameters may need retrieval from SI
- Performance estimates are grounded in synthetic ONT and PB reads with specific error profiles; real-data error models may differ
