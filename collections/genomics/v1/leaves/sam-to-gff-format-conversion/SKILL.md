# sam-to-gff-format-conversion

## Summary

Converts minimap2 splice-mode SAM alignments of FLNC single-cell reads into GFF format with the sam2gff.pl script (from gpertea/gscripts), a prerequisite for gffcompare-based assignment of FLNC transcripts to annotated genes in the scISA-Tools HIT-scISOseq pipeline.

## When to use

Use when SAM alignments of PacBio FLNC single-cell reads must be converted to GFF so that gffcompare can compare them against a reference annotation GTF.

## When NOT to use

- Alignments are not from full-length non-chimeric (FLNC) transcript reads or were not produced by splice-aware minimap2 settings — the GFF transcript reconstruction assumes splice-aligned transcript reads
- Downstream step needs per-read SAM records (e.g. read-level quality or coordinate inspection) rather than collapsed GFF transcript features

## Inputs

- isoseq_flnc.Transcript.sam — SAM file of FLNC reads aligned to the reference genome with minimap2 splice mode ('-ax splice -uf --secondary=no -C5')

## Outputs

- isoseq_flnc.Transcript.gff — GFF transcript features corresponding to the SAM alignments, ready for gffcompare against ref.genes.gtf

## How to apply

In the scISA-Tools workflow, FLNC reads (generated by classify_by_primer with '-min_primerlen 16 -min_isolen 50') are first aligned to the reference genome with minimap2 in splice mode ('-ax splice -uf --secondary=no -C5'), producing isoseq_flnc.Transcript.sam. The sam2gff.pl script — originally from gpertea/gscripts — transforms this SAM file into a transcript GFF (isoseq_flnc.Transcript.gff) by reading alignment blocks and emitting GFF gene/transcript/exon features. The GFF is then consumed by 'gffcompare -r ref.genes.gtf' to produce a tmap that assigns each FLNC transcript to an annotated gene via tmap match codes. Run the conversion immediately after mapping and before tmap filtering (filter.tmap.pl) and single-cell matrix generation (scGene_matrix), since downstream steps require the GFF/tmap representation rather than SAM.

## Related tools

- **sam2gff.pl** (Perl script (originally from gpertea/gscripts) that transforms the minimap2 SAM alignment of FLNC reads into GFF format) — https://github.com/gpertea/gscripts/blob/master/sam2gff.pl

## Examples

```
perl sam2gff.pl isoseq_flnc.Transcript.sam > isoseq_flnc.Transcript.gff
```

## Evaluation signals

- The output GFF (isoseq_flnc.Transcript.gff) exists in the output directory after running sam2gff.pl on isoseq_flnc.Transcript.sam
- GFF records correspond one-to-one with the splice-aligned transcript records in the input SAM (all mapped FLNC reads represented)
- gffcompare runs without format errors on the GFF against ref.genes.gtf and produces flnc.isoseq_flnc.Transcript.gff.tmap
- Downstream filtering ('perl filter.tmap.pl flnc.isoseq_flnc.Transcript.gff.tmap > flnc.filtered.tmap') succeeds, confirming valid upstream GFF

## Limitations

- sam2gff.pl depends on the input SAM being produced by splice-mode minimap2 ('-ax splice -uf --secondary=no -C5'); non-splice alignments may not convert into correct transcript structures
- Conversion is a formatting step only — it does not assign transcripts to genes; that requires the subsequent gffcompare run against the reference GTF
