# horizontal-pleiotropy-iv-classification-verification

## Summary

Verifies that instruments generated by simmrd's predefined MR simulation scenarios (CHP, UHP, UHP+CHP, weak-IV variants) carry the expected horizontal pleiotropy class by checking the per-IV IVtype vector returned by generate_summary()/generate_individual().

## When to use

Use when simulating MR data with simmrd presets and you must confirm each replicate labels instruments as 'valid', 'UHP', or 'CHP' in counts matching the configured pleiotropy model before downstream MR-method evaluation.

## When NOT to use

- When analysing real GWAS summary statistics rather than simulated data — IVtype labels only exist for simmrd-generated replicates
- When the goal is to estimate causal effects rather than verify simulation ground truth — this skill validates instrument class labels, not MR estimates
- When using generate_individual() purely for speed — it is slower; generate_summary() is the faster path suitable for most simulation studies

## Inputs

- simmrd parameter list from load_preset() or set_params() (e.g. preset 'CHP' with n=1e5, snps=100, exposures=1, overlap='none')
- Generated replicate object from generate_summary() containing bx, by, bxse, byse matrices and the IVtype vector
- Weak-instrument parameter settings (simtype = 'weak', fix_Fstatistic_at = 10)

## Outputs

- Per-scenario replicate objects with correctly dimensioned bx/by matrices and an IVtype vector whose 'valid'/'UHP'/'CHP' counts match the preset configuration
- Verified mean first-stage F-statistic centred at fix_Fstatistic_at for weak-IV scenarios
- A single RDS file aggregating all per-scenario replicate objects for downstream MR-method evaluation

## How to apply

Install simmrd from github.com/noahlorinczcomi/simmrd, enumerate scenarios with list_presets(), and load each with load_preset() (e.g. 'CHP' with n=1e5, snps=100, exposures=1, overlap='none'; 'UHP_CHP' with n=1e5, snps=500, exposures=3, overlap='full'), overriding parameters such as true_causal_effects as needed. Pass the parameter list to generate_summary() to produce one replicate of summary-level GWAS data containing bx, by, bxse, byse, and the IVtype vector. Inspect IVtype, which classifies each IV as 'valid', 'UHP', or 'CHP', and confirm the counts match the preset configuration (e.g. number_of_CHP_causal_SNPs = 20 for the CHP scenario); note that preset pleiotropy parameters scale with snps — 20% of SNPs are pleiotropic for single-bias scenarios and 10% each for combined UHP_CHP scenarios. For weak-instrument configurations (simtype = 'weak' with fix_Fstatistic_at = 10), compute the mean first-stage F-statistic from bx and bxse and confirm it is centred on the requested value. Write per-scenario replicate objects to a single RDS file for downstream evaluation of MR estimators.

## Examples

```
params <- load_preset("CHP", n = 1e5, snps = 100, exposures = 1, overlap = "none"); data <- generate_summary(params); table(data$IVtype)
```

## Evaluation signals

- Each replicate object exists with correctly dimensioned bx (m x p) and by (m x 1) matrices plus bxse/byse
- IVtype vector class counts match the preset's UHP/CHP/valid configuration (e.g. number_of_CHP_causal_SNPs = 20 for the CHP scenario)
- For weak presets, mean first-stage F-statistic computed from bx and bxse is centred on the fix_Fstatistic_at target (e.g. 10)
- Preset pleiotropy scaling holds: 20% pleiotropic SNPs for single-bias scenarios, 10% each for UHP_CHP / UHP_CHP_WEAK
- All per-scenario replicate objects are written to one RDS file without loss of the IVtype element

## Limitations

- generate_summary() and generate_individual() each produce data for a single simulation replicate only; multi-replicate Monte Carlo runs require the CLI or iteration
- The associated paper draft (simmr-5.pdf) is a working paper that has not been peer-checked or reviewed
- No version number is stated for simmrd or R in the documentation
- simmrd relies on estimated LD (LDhatMatrix) as well as true LD (LDMatrix), so imprecise LD estimation is part of the simulated data by design
