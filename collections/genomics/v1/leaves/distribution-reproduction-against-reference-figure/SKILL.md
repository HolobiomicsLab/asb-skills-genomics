# distribution-reproduction-against-reference-figure

## Summary

Reproduces a published figure's statistical distribution — here the per-dataset compression ratios |W_nsop|/|W_all| of Fig. 2 of the uTR paper — by regenerating the exact benchmark inputs (48 simulated mosaic tandem repeat datasets from test_public/gendata) and recomputing the statistic from scratch.

## When to use

Use when a paper reports a summary distribution (e.g., histogram or ratio distribution) over synthetic benchmark datasets and you must regenerate the inputs from the authors' data-generation code and recompute the statistic to validate the figure.

## When NOT to use

- Your goal is decomposing real long reads into mosaic tandem repeats — use uTR itself; this skill only reproduces the candidate-unit compression analysis of Fig. 2
- You need units longer than 20 nt — uTR/mTR handle long units (>20nt via mTR), but this compression analysis is defined only for the <=20 nt substring space
- You lack the test_public gendata code or an equivalent generator for the 48 synthetic configurations; substituting different datasets would not reproduce Fig. 2

## Inputs

- 48 simulated mosaic tandem repeat datasets generated by test_public/gendata (1000 random instances per configuration, e.g. (AC)m(AG)n)
- Substring length cutoff parameter (20 nt), matching uTR's default unit length limit

## Outputs

- compression_ratios.csv with 48 rows, one |W_nsop|/|W_all| compression ratio per benchmark dataset
- Distribution summary (histogram/description) comparable to Fig. 2

## How to apply

First regenerate the benchmark inputs exactly as the authors did: compile the test_public codes with make.sh and use gendata to produce the 48 simulated mosaic tandem repeat configurations (e.g., (AC)m(AG)n), with 1000 random instances per configuration. For each dataset, enumerate all unique substrings of length <=20 nt to form W_all, mirroring uTR's default that it 'automatically estimates tandem repeat units of length 20 nt or less'. From W_all, extract only non-self-overlapping substrings to form W_nsop, and compute the compression ratio |W_nsop|/|W_all| per dataset; write the 48 ratios to compression_ratios.csv, one row per dataset. Finally, inspect the distribution and judge success by whether it matches Fig. 2 — the paper's expected outcome is that most ratios are 5% or less, demonstrating that restricting candidates to non-self-overlapping substrings sharply reduces the candidate unit space.

## Related tools

- **uTR** (Source repository whose test_public/gendata codes generate the 48 synthetic mosaic tandem repeat benchmark datasets used to recompute the compression-ratio distribution; uTR's <=20 nt default unit length defines the substring space) — https://github.com/morisUtokyo/uTR

## Examples

```
python -c "import csv,re; seq=open('dataset.fasta').read().split('\n',1)[1]; W_all={seq[i:i+L] for L in range(1,21) for i in range(len(seq)-L+1)}; W_nsop={w for w in W_all if not re.search(r'(.+)\1',w)}; print(len(W_nsop)/len(W_all))"
```

## Evaluation signals

- compression_ratios.csv contains exactly 48 ratio entries, one per benchmark dataset
- The majority of compression ratios are 5% or less, consistent with the Fig. 2 distribution
- Per-dataset ratios are in (0,1] since W_nsop is a subset of W_all
- Each synthetic dataset contains 1000 random instances, matching the gendata configuration used for accuracy tables like '998 1000' for (AC)m(AG)n with m,n in 2..500

## Limitations

- The result is specific to the 48 synthetic configurations and the <=20 nt substring space; ratios for longer units (requiring mTR) or real data are not characterized here
- Reproduction depends on the uTR repository's gendata code being unchanged; regenerated random instances may differ in detail from the original runs (1000 random instances per configuration)
- Defining 'non-self-overlapping' substrings requires an overlap criterion (periodicity); divergent definitions of self-overlap will change |W_nsop| and the ratio distribution
