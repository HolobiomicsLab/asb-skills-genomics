# consensus-sequence-accuracy-assessment

## Summary

Quantifies the accuracy of de novo full-length 16S rRNA gene consensus sequences generated by nanoClust from noisy nanopore reads, by aligning each consensus against a SILVA reference and measuring sequence identity, and characterizes how accuracy depends on the number of reads used per consensus.

## When to use

Use when nanopore amplicon consensus sequences (e.g., nanoClust output from 2D or 1D2 reads) must be quality-scored against reference 16S sequences, or when deciding how many reads (5, 10-15, >=50) are needed per OTU consensus.

## When NOT to use

- Input is a feature/OTU table or classification-only output rather than raw or INC-Seq-processed nanopore reads — this skill requires re-clustering and consensus calling from reads
- No reference 16S sequence (e.g., SILVA entry) exists for the organism, so percent identity against a reference cannot be computed
- Data are short Illumina MiSeq or Ion Torrent PGM reads, where the nanopore-specific accuracy plateau and homopolymer deletion error modes do not apply

## Inputs

- 2D and 1D2 nanopore amplicon read sets (one-organism and 1-/10-organism mock communities) from the umerijaz/nanopore repository
- chopSeq-processed INC-Seq consensus reads (fragmented, orientation-corrected)
- SILVA 16S rRNA reference sequences for the organism(s) under test
- nanoClust consensus FASTA files (full-length 16S rRNA gene sequences)

## Outputs

- accuracy_curve.png plotting consensus sequence identity versus subsampled read count
- consensus FASTA of full-length 16S rRNA gene sequences
- partition_sweep_results.csv with OTU counts and accuracy values per partition count (1-7)
- Per-OTU percent-identity scores against SILVA references

## How to apply

Subsample n reads per OTU (n = 5 to 100) from the one-organism 2D and 1D2 nanopore amplicon read sets in the umerijaz/nanopore repository, run nanoClust read-partitioning-based de novo clustering plus within-cluster consensus calling on each subsample, then align each full-length 16S rRNA gene consensus sequence to the organism's SILVA 16S reference and record percent sequence identity as the accuracy metric. Plot accuracy versus subsampled read count to locate the key thresholds: accuracy surpasses 99% above 5 reads, plateaus at roughly 10-15 reads, and is only reliably high at >=50 reads. For the partition-count ablation (1-7 partitions on chopSeq-processed INC-Seq consensus reads), tabulate OTU counts and accuracy per partition setting and verify that the optimal low-partition setting reproduces the reported average consensus accuracy of 99.5% for both 2D and 1D2 sequencing. Expect residual errors to concentrate in homopolymer-region deletions.

## Evaluation signals

- Consensus accuracy surpasses 99% when more than five reads are used for consensus construction
- Accuracy plateaus at approximately 10-15 reads per OTU consensus and is reliably high only when at least 50 reads are available
- Consensus accuracy at the optimal (low) partition setting matches the reported average of 99.5% for 2D and 1D2 sequencing
- As partition count increases from 1 toward 7, OTU count inflates above the theoretical threshold while average accuracy decreases
- Residual errors are dominated by deletions in homopolymer regions rather than mismatches

## Limitations

- Consensus accuracy is reliable only with >=50 reads per OTU; with 5-15 reads accuracy plateaus but is not dependable at the low end
- Nearly all residual errors originate from deletions in homopolymer regions, a systematic nanopore error mode not removed by the de novo workflow
- Detected OTU count is sensitive to nanoClust partition length: more partitions inflate OTUs above the theoretical number of organisms
