# non-self-overlapping-substring-computation

## Summary

Reduces the candidate repeat-unit search space for mosaic tandem repeat analysis by restricting enumeration to non-self-overlapping (nsop) substrings of length <= 20 nt, as used by uTR. This skill quantifies the resulting |W_nsop|/|W_all| compression ratio (Fig. 2 of the uTR paper) on the 48 synthetic benchmark datasets.

## When to use

Use when enumerating candidate tandem repeat units for uTR-style decomposition and you need to restrict the search to non-self-overlapping substrings of length <= 20 nt, or to quantify the search-space reduction this restriction achieves.

## When NOT to use

- You need repeat units longer than 20 nt — the article directs long-unit computation to mTR instead ('Long units (of length > 20nt, for example) can be computed by using mTR')
- The goal is to decompose reads into mosaic tandem repeat patterns itself rather than to characterize or prune the candidate unit space — use uTR directly for decomposition

## Inputs

- Simulated mosaic tandem repeat datasets generated by gendata in uTR's test_public directory (e.g., 1000 instances of (AC)m(AG)n per configuration)
- FASTA-formatted DNA strings containing mosaic tandem repeats (e.g., realdata/realdata.fasta)

## Outputs

- compression_ratios.csv with 48 rows, one |W_nsop|/|W_all| compression ratio per benchmark dataset
- Per-dataset sets W_all (all unique substrings of length <= 20 nt) and W_nsop (non-self-overlapping subset)

## How to apply

For each input sequence dataset, first enumerate all unique substrings of length 20 nt or less to form the set W_all; 20 nt is the unit-length ceiling uTR itself uses when it automatically estimates units ('If it is not specified, uTR automatically estimates tandem repeat units of length 20 nt or less'). Then extract the subset W_nsop containing only non-self-overlapping substrings — i.e., substrings that cannot overlap with shifted copies of themselves — and compute the compression ratio |W_nsop|/|W_all| per dataset. To reproduce the paper's Fig. 2 evaluation, generate the 48 simulated mosaic tandem repeat datasets (1000 random instances per configuration, e.g. (AC)m(AG)n) using the gendata codes in the test_public directory of the uTR repository, compile with make.sh, and write the 48 per-dataset ratios to compression_ratios.csv. The rationale is that the vast majority of candidate substrings in tandem-repeat-rich strings are self-overlapping artifacts (e.g., of (AC)m runs), so the nsop filter removes them without losing true repeat units.

## Related tools

- **uTR** (Provides the 20 nt unit-length ceiling and the simulated benchmark datasets (test_public/gendata) on which the non-self-overlapping substring enumeration is evaluated; its decomposition uses these candidate units) — https://github.com/morisUtokyo/uTR
- **mTR** (Complementary tool for units exceeding the 20 nt ceiling, outside the scope of this nsop substring computation) — https://github.com/morisUtokyo/mTR

## Examples

```
cd uTR/test_public && ./make.sh && ./test.sh  # generate the 48 simulated (AC)m(AG)n-style datasets, then enumerate length<=20 substrings to compute |W_nsop|/|W_all| per dataset
```

## Evaluation signals

- compression_ratios.csv contains exactly 48 ratio entries, one per benchmark dataset configuration
- The majority of the 48 compression ratios are 5% or less, matching the Fig. 2 distribution of |W_nsop|/|W_all|
- W_all contains all unique substrings of length <= 20 nt (sanity check: for a pure (AC)m repeat, most of W_all is self-overlapping, so the ratio must be small)
- W_nsop is a strict subset of W_all, so every ratio is in (0, 1]; ratios near 1 would indicate the nsop filter is not being applied correctly
- Benchmark datasets are generated with 1000 random instances per configuration, matching the gendata/test_public protocol (e.g., m and n ranged from 2 to 20 up to 2 to 500)

## Limitations

- The restriction applies only to units of length <= 20 nt; longer units require a different tool (mTR) and are not covered by this skill
- The finding that most ratios are 5% or less was established on the 48 synthetic mosaic tandem repeat benchmarks; datasets dominated by longer or more divergent units may show different compression behavior
- uTR's default parameter set (e.g., maximum dissimilarity ratio 0.3 defined via MAX_DIS_RATIO_DEFAULT in uTR.h) governs downstream decomposition, not the nsop substring enumeration itself
