# bulk-long-read-and-scrnaseq-integration

## Summary

A hybrid strategy that integrates bulk long-read (ENCODE PacBio, mouse cortex/hippocampus) transcriptome definition with single-cell Illumina short-read (Smart-Seq2) counts to estimate isoform expression at the single-cell level, enabling downstream isoform co-expression and DIU/coDIU analysis with acorde.

## When to use

Use when single-cell short-read counts must be projected onto isoforms defined by a bulk long-read transcriptome — e.g. combining ENCODE PacBio mouse cortex/hippocampus isoforms with Tasic Smart-Seq2 scRNA-seq counts to study isoform co-usage across cell types.

## When NOT to use

- If you only need gene-level scRNA-seq differential expression — this skill resolves isoform-level co-usage, which requires long-read-defined transcriptomes
- If no bulk long-read data are available and you need de novo functional annotation of isoforms: acorde/isoAnnotLite relies on pre-annotated compatible references (e.g. tappAS mouse RefSeq), and de novo isoform annotation tooling is still work-in-progress
- If the goal is transcriptome assembly/QC of the long reads themselves — use SQANTI3, which is not part of the acorde package's co-usage analysis block

## Inputs

- Bulk ENCODE PacBio long-read mouse cortex/hippocampus transcriptome (long-read-defined isoform models)
- Single-cell Smart-Seq2 (Illumina) isoform-level expression/counts matrix with cell-type identity labels
- Isoform-to-gene relationships file

## Outputs

- Single-cell isoform-level expression matrix (isoform × cell) used as acorde input
- Filtered set of differentially expressed isoforms across cell subtypes (e.g. 568 DE isoforms for the Tasic GABA-ergic subtypes)
- Isoform expression data underlying percentile-correlation clustering and DIU/coDIU gene sets

## How to apply

First define the transcriptome from bulk long reads (bulk ENCODE PacBio long-read data from mouse cortex and hippocampus, generated by Wyman et al.); note that this long-read transcriptome-building strategy is outside the acorde R package and is described in the manuscript's dedicated Supplementary Note. Second, integrate these long-read-defined isoforms with single-cell Illumina/Smart-Seq2 counts (e.g. Tasic et al. primary visual cortex, five GABA-ergic subtypes Lamp5, Pvalb, Sncg, Sst, Vip; 4921 cells post-QC) to estimate isoform expression per cell. Third, perform a differential expression filter on the resulting isoform-level matrix across subtypes (568 DE isoforms in the Tasic GABA-ergic reproduction). The quantified isoform matrix, isoform-to-gene relationships, and cell type labels then feed acorde's percentile-correlation clustering and DIU/coDIU steps, since naive per-cell isoform quantification is too sparse for standard correlation estimates.

## Related tools

- **acorde** (R package consuming the integrated single-cell isoform expression matrix for co-expression clustering and DIU/coDIU analysis) — https://github.com/ConesaLab/acorde
- **tappAS** (provides pre-annotated mouse transcriptome references used to transfer functional labels onto the long-read-defined isoform models via isoAnnotLite) — https://github.com/ConesaLab/tappAS

## Evaluation signals

- On the Tasic 2018 GABA-ergic subset, the DE filter across Lamp5/Pvalb/Sncg/Sst/Vip must yield 568 significant DE isoforms
- Downstream DIU/coDIU check: 22 DIU genes, of which 16 coDIU genes involving 36 isoforms — mismatches flag the integrated run as failed
- Isoform clustering after quantification should merge into 5 final co-expression profile clusters
- The quantified isoform expression matrix should match the internal package data shipped with acorde (the dataset used in the manuscript)
- Cell count post-QC should be 4921 cells across the five subtypes before quantification

## Limitations

- The acorde R package does not include the long-read transcriptome building procedure; reproduction requires the manuscript's Supplementary Note protocol
- Single-cell isoform expression is sparse, hence standard correlations fail — percentile correlations were developed specifically to overcome this sparsity
- Functional annotation of long-read isoforms requires an annotation-compatible reference (IsoAnnotLite v2.6 with tappAS mouse RefSeq/RefSeq108); de novo annotation is not yet available
