# eventalign-signal-orientation-flipping

## Summary

Preprocessing step for nanopore direct RNA data in which per-5-mer signal lists from Nanopolish eventalign (produced in 3'–5' order) are flipped to 5'–3' orientation before concatenating signals from overlapping 5-mers, so that 9-mer contexts are correctly assembled for CHEUI m6A/m5C model input.

## When to use

Reference for nanopore direct RNA pipelines using Nanopolish eventalign output where per-k-mer signal samples must be reordered to 5'–3' before building fixed-length (5 × 20 = 100) 9-mer feature vectors for deep-learning modification callers.

## When NOT to use

- If signals were generated by a tool that already emits 5'–3'-ordered k-mer samples (e.g. non-Nanopolish resquiggling), an unconditional flip may invert correct ordering.
- If the downstream model does not use overlapping 5-mer windows around a central modified base (different context size), the 9-mer assembly and flip are unnecessary.

## Inputs

- Nanopolish eventalign output (nanopolish_out.txt) with per-5-mer signal lists and read IDs, generated with --scale-events --signal-index --samples --print-read-names
- Sorted BAM of reads aligned to a reference transcriptome with minimap2, filtered for primary positive-strand alignments
- Basecalled reads (Guppy 4.0.11+, RNA r9.4.1 70bps model)

## Outputs

- CHEUI preprocessing input file (e.g. cheui_model1_input_signals.tsv) with read ID, sequence context, observed length-100 signal vector (5 × 20 medians), and matching length-100 distance vector per read/9-mer

## How to apply

Run Nanopolish eventalign with --scale-events --signal-index --samples --print-read-names so each event row carries the per-5-mer signal samples and read IDs. Because Nanopolish emits the event/signal lists in transcript 3'–5' orientation, flip each 5-mer's signal list to 5'–3' ordering before concatenating signals from overlapping 5-mers — skipping this flip misaligns features across the centered 9-mer (NNNN(A|C)NNNN). For each position of interest (adenosine for m6A, cytosine for m5C), collect the five consecutive overlapping 5-mers covering the 9-mer, convert each 5-mer into a 20-segment median vector (padding with the overall median if fewer than 20 values), and concatenate to the length-100 observed vector; a companion distance vector against the Nanopolish k-mer model expected values is built from the same oriented signals. Downstream CHEUI preprocessing scripts (CHEUI_preprocess_m6A.py vs CHEUI_preprocess_m5C.py) consume this ordered signal file.

## Related tools

- **Nanopolish eventalign** (Resquiggles read signals to the aligned transcript and emits per-5-mer signal samples that are subsequently flipped to 5'–3')
- **CHEUI preprocessing scripts (CHEUI_preprocess_m6A.py / CHEUI_preprocess_m5C.py)** (Consume the flipped eventalign signals to assemble the 9-mer signal and distance vectors for CHEUI Model 1) — github.com/comprna/CHEUI-public
- **minimap2** (Aligns basecalled reads to the reference transcriptome upstream of eventalign, producing the BAM eventalign needs)

## Examples

```
nanopolish eventalign -t 48 --reads <read fastq> --bam <sorted-bam-file> --genome <transcriptome fasta> --scale-events --signal-index --samples --print-read-names > nanopolish_out.txt
```

## Evaluation signals

- Every output record contains two vectors of exactly length 100 (5 consecutive 5-mers × 20 segments), matching the CHEUI-solo Model 1 input specification.
- Signal ordering within each 20-segment vector follows 5'–3' direction consistent with the transcript reference, not the raw eventalign 3'–5' output order.
- Each output row is tied to a valid read ID (nanopolish run with --print-read-names) and its 9-mer context centered on the candidate modified base.
- Downstream CHEUI model 1 accepts the file without dimension errors, confirming vector shape and orientation.

## Limitations

- Eventalign output orientation is an artifact of Nanopolish's emission order; the flip must be paired with the correct window definition (five overlapping 5-mers around the central base) or features become misaligned.
- Variable numbers of signal samples per 5-mer require padding with the overall median, which can degrade feature quality for low-coverage events.
