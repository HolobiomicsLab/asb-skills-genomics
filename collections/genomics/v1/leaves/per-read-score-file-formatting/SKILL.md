# per-read-score-file-formatting

## Summary

Reformat heterogeneous per-read methylation scores from Nanopore 5mC calling tools (Nanopolish, DeepSignal, Tombo, Guppy, Megalodon, DeepMod) into METEORE's unified per-read TSV format (ID, Chr, Pos, Strand, Score) so tool outputs can be combined by consensus models.

## When to use

Use when per-read methylation predictions from multiple nanopore methylation callers must be merged into a common format before training or applying METEORE's random forest or multiple linear regression combination models.

## When NOT to use

- Only one tool's predictions are needed and no consensus/combination model will be applied
- Input is already a per-read score TSV in METEORE format
- The goal is per-site aggregation only, with no per-read tool comparison (a simple per-site summary suffices)

## Inputs

- Tool-native methylation output files from Nanopolish, DeepSignal, Tombo, Guppy, Megalodon, or DeepMod
- Single-read fast5 files (converted with multi_to_single_fast5 from ont_fast5_api)
- Reference genome FASTA (e.g. data/ecoli_k12_mg1655.fasta)

## Outputs

- Per-read score TSV files with fields ID, Chr, Pos, Strand, Score for each selected tool
- Combined-model input file ready for METEORE's random forest or multiple linear regression
- Optional augmented BED per-site outputs with methylation frequency and coverage

## How to apply

Run each methylation-calling tool's Snakemake pipeline (Snakefiles named Nanopolish, Deepsignal1, Tombo, Guppy, plus Megalodon/DeepMod) on single-read fast5 inputs against the ecoli_k12_mg1655.fasta reference to obtain tool-native outputs. Convert each tool's output so every CpG prediction is a row with read ID, chromosome, position, strand, and a per-read methylation score; DeepSignal needs a second Conda environment step to produce result files 'in the same format generated by other tools'. Prepare these per-read score files as the input for the combined model, optionally tuning regression options such as --filter (percentage of reads removed around mean score, default -1/disabled), trunc_min/trunc_max score truncation, --no_scaling, and --inc_pred. The rationale is that the consensus approach (METEORE) improves accuracy only if predictions from the two or more tools are aligned per read and site on a common schema.

## Evaluation signals

- Each per-read score file contains exactly the five columns: ID, Chr, Pos, Strand, Score
- Read/site identifiers in the formatted files align consistently across all tools so rows can be joined per read and CpG position
- The combined model runs without parsing errors on the prepared input file, and optional parameters (--filter, trunc_min/trunc_max, --no_scaling, --inc_pred) apply without dropping unintended rows
- Downstream per-site predictions (methylation frequency, coverage) in augmented BED format are reproducible from the formatted per-read files

## Limitations

- DeepMod's per-site augmented BED output was not yet supported (README notes it 'will be updated very soon')
- Combining multiple tools can be impractical for routine analyses because tools without GPU support have long running times
- Individual tools disagree heavily (e.g. Guppy fails at fully methylated sites; Nanopolish and Tombo show false positives at unmethylated sites), so score formatting must preserve strand and score fidelity to avoid masking these biases
