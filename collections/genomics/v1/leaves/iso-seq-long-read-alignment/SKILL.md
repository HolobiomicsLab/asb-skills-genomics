# iso-seq-long-read-alignment

## Summary

Align PacBio Iso-seq full-length transcript FASTA reads to a reference genome (e.g., hg38) using TAGET's TransAnnot with minimap2 and/or HISAT2, producing annotated junctions, transcript classifications, and bed/stat outputs. This is the foundational alignment-and-annotation step of the TAGET toolkit for accurate splice-junction recovery.

## When to use

Use when input is a full-length transcript FASTA from PacBio Iso-seq (CCS reads) and accurate splice-junction detection and transcript annotation against a reference genome such as hg38 is needed.

## When NOT to use

- Input data is short-read RNA-seq rather than full-length Iso-seq transcripts; TAGET is designed for Iso-seq data from alignment to downstream quantification.
- Only a high-level gene/transcript expression matrix is needed and no junction-level annotation is required — TransAnnotMerge or RNA-seq-based quantification may be more appropriate.
- The reference annotation and genome for the target organism are unavailable, since both HISAT2 and minimap2 need the indexed reference genome and a GTF annotation.

## Inputs

- Full-length transcript FASTA from PacBio Iso-seq (CCS reads)
- Reference genome FASTA (hg38.fa)
- Ensembl GTF transcript annotation (hg38.ensembl.gtf)
- gtf pickle database generated by gtf_db_make.py
- HISAT2 index built with hisat2-build

## Outputs

- {sample_id}.annot.junction (splice junction information)
- {sample_id}.annot.stat (per-read classification, gene/transcript annotation)
- {sample_id}.annot.bed (annotated genes in bed format)
- {sample_id}.annot.multiAnno (multi-annotation transcripts)
- {sample_id}.fa.minimap2.bed and {sample_id}.fa.hisat2.bed (per-aligner mapped bed files)

## How to apply

Download the hg38 reference genome (hg38.fa) and an Ensembl GTF annotation (e.g., hg38.ensembl.gtf), and build the annotation pickle database with gtf_db_make.py since both HISAT2 and minimap2 need the indexed reference. Configure TransAnnot.Config with paths to HISAT2/minimap2, the HISAT2 index generated by hisat2-build, the genome FASTA, the GTF annotation, and HISAT2 parameters read length 100, read overlap 80, and minimum read length 30. Run TransAnnot.py with the full-length transcript FASTA, optionally enabling both minimap2 (--use_minimap2 1) and HISAT2 (--use_hisat2 index), since the fusion-detection workflow relies on combining the minimap2 bed (.fa.minimap2.bed) with the HISAT2 bed (.fa.hisat2.bed). The run completes in under 1 hour on 8 cores and produces per-sample outputs including {sample_id}.annot.junction, {sample_id}.annot.stat, and {sample_id}.annot.bed. Junctions recovered in the .annot.junction file can then be compared against a truth set (e.g., junctions from partially deleted reference genes) to compute junction-recovery sensitivity and precision.

## Examples

```
python TransAnnot.py -c TransAnnot.Config
```

## Evaluation signals

- The output directory contains all expected files: {sample_id}.annot.bed, .annot.stat, .annot.db.pickle, .annot.cluster.gene, .annot.cluster.transcript, .annot.cluster.reads, .annot.junction, and .annot.multiAnno.
- The .annot.stat file has all documented columns (ID, Classification, Subtype, Gene, Transcript, Chrom, Strand, Seq_length, Seq_exon, etc.) and classifications restricted to FSM/ISM/NIC/NNC/GENIC/INTERGENIC/FUSION/UNKNOWN.
- In a partial-annotation benchmark, junction sensitivity and precision per tool per deletion level (5/10/20/30/50%) are tabulated and TAGET sensitivity exceeds StringTie2 and FLAIR at the levels reported in Supplementary Fig. 5.
- Fraction of predicted novel junctions that are non-canonical is low, consistent with TAGET's claim of more precise novel splice-site prediction than default alignments.
- The full run finishes in under 1 hour on 8 cores, matching the documented runtime.

## Limitations

- Iso-seq preprocessing filters CCS-read clusters containing only one read due to lower quality, removing about 80% of CCS reads, many of which come from true expressed isoforms, limiting gene detection.
- The effective coverage of Iso-seq is substantially reduced because CCS reads repeatedly sequence single nucleotides.
- At least one of HISAT2/minimap2/GMAP plus samtools, python3 with rpy2/pandas/numpy, and R >= 3.3 with stringr/optparse/DEGseq are environmental dependencies, on Linux/CentOS.
