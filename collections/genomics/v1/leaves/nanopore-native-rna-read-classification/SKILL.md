# nanopore-native-rna-read-classification

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Classify individual native Nanopore dRNA-seq reads as premature or mature using Nanodynamo's fractionsReadsClassification-style thresholding of nano-ID modification-probability scores against labeled/unlabeled training distributions.

## When to use

Use when you have native RNA Nanopore reads from a subcellular fraction (e.g. chromatin, nucleoplasm, cytoplasm) and need per-read premature vs. mature labels to estimate processing-state fractions.

## When NOT to use

- Reads come from PCR-cDNA or amplified Nanopore libraries rather than native RNA sequencing — the modification-probability signal the classifier thresholds on is generated by the native-RNA chemistry
- The goal is to quantify synthesis/processing/degradation kinetic rates rather than to classify individual reads — use the nano-ID model fitting (nanoIDMain.R) instead
- Input reads are already labeled by metabolic-labeling ground truth (4sU/s4U labeling status known), so classification is unnecessary

## Inputs

- Native Nanopore dRNA-seq reads from a subcellular fraction (e.g. nano-COP K562 chromatin RNA, GEO GSM4663623)
- Trained nano-ID classifier
- nanoID.modification.probabilities.labeled.RData (labeled training modification probabilities)
- nanoID.modification.probabilities.unlabeled.RData (unlabeled training modification probabilities)

## Outputs

- Per-read premature/mature classification labels
- Summary premature-read fraction per cellular fraction (e.g. premature_fraction.csv)

## How to apply

Load the native Nanopore dRNA-seq reads into R together with the trained nano-ID classifier and the nano-ID training data files (nanoID.modification.probabilities.labeled.RData and nanoID.modification.probabilities.unlabeled.RData) from the Nanodynamo repository. Run the fractionsReadsClassification-style procedure, which assigns each read a premature or mature label by thresholding its modification-probability scores against the labeled and unlabeled training distributions. Aggregate the per-read labels to compute the fraction of premature reads for the fraction of interest, then write per-read labels and the summary fraction (e.g. to premature_fraction.csv). Rationale: chromatin-associated RNA should be enriched in premature transcripts, so applying the classifier to a chromatin sample provides a direct sanity check; in the nano-COP K562 chromatin sample (GEO GSM4663623) this yields ~83% premature reads, matching the paper's reported value.

## Related tools

- **Nanodynamo** (Provides the fractionsReadsClassification.R R script and core functions used to characterize nascent and premature read fractions) — https://github.com/mfurla/Nanodynamo
- **nano-ID model** (Machine-learning classifier (metabolic labeling + native Nanopore long reads) whose modification-probability scores are thresholded to label reads premature or mature) — https://github.com/birdumbrella/nano-ID
- **R** (Execution environment for the classification script and the labeled/unlabeled .RData training objects)

## Examples

```
Rscript fractionsReadsClassification.R  # load nano-ID classifier + labeled/unlabeled .RData, threshold modification probabilities, write premature_fraction.csv
```

## Evaluation signals

- Applying the classifier to the nano-COP K562 chromatin dRNA-seq sample (GEO GSM4663623) reproduces ~83% premature reads, matching the paper's reported value
- Every read in the output receives exactly one of the two labels (premature or mature); no unclassified reads remain
- The summary premature fraction equals the mean of the per-read binary labels aggregated in step 4
- Classification thresholds faithfully reproduce the labeled/unlabeled training distributions loaded from nanoID.modification.probabilities.labeled.RData and nanoID.modification.probabilities.unlabeled.RData
- Cytoplasmic/published chromatin fractions show the expected polarity: chromatin RNA enriched in premature reads relative to more mature downstream fractions

## Limitations

- Classifier performance depends on the labeled/unlabeled training distributions from nano-ID; data generated with different library chemistry or labeling protocols may shift modification-probability scores and misclassify reads
- The threshold-based labels are probabilistic, so the premature fraction is an estimate, not a ground-truth count
- Validation was demonstrated on chromatin RNA where premature enrichment is expected; fractions dominated by mature transcripts give weaker signal to validate against
