# mrna-quality-statistics-reporting

## Summary

Automated quality-control reporting for synthetic mRNA using the Mana command-line toolkit, which analyses Oxford Nanopore Technologies (ONT) alignment BAM files to report sequence identity, integrity, 3'-poly(A) tail length, and contamination statistics. It supports the VAX-seq protocol by producing detailed, automated QC reports from a single integrated long-read analysis.

## When to use

Use when you have a sorted, indexed ONT alignment BAM against an mRNA or plasmid reference and need automated mRNA quality-control statistics (sequence identity, integrity, poly(A) tail length, purity) for vaccine or therapy QC.

## When NOT to use

- Input is raw Nanopore FASTQ/POD5 that has not yet been aligned and converted to a sorted, indexed BAM — Mana requires .BAM alignments as input
- The goal is nucleoside-modification chemistry analysis (e.g. N1-methylpseudouridine detection), which requires direct RNA sequencing rather than Mana's cDNA-alignment QC reports
- Short-read Illumina data without a corresponding ONT alignment BAM, since Mana analyses ONT alignments specifically

## Inputs

- Sorted and indexed ONT alignment BAM file (generated by Minimap2 -ax map-ont and SAMtools v1.15)
- Reference sequence FASTA file (plasmid or mRNA reference)
- Output directory path for the QC reports

## Outputs

- Mana QC report files reporting mRNA quality statistics (sequence identity, integrity, poly(A) tail length, contamination) written to the output directory

## How to apply

Prepare a sorted, indexed BAM by aligning ONT reads (with barcodes removed via Porechop v0.2.4) to the plasmid/mRNA reference using Minimap2 2.20-r1064 with '-ax map-ont', then processing with SAMtools v1.15. Retrieve the pre-built Mana Docker image with 'docker pull scchess/mana' and tag it as 'mana', then mount the working directory with '-v ${PWD}:/src' so inputs are visible at /src. Run 'python3 mana.py' in --mrna mode, passing the ONT alignment BAM via '-b', the reference FASTA via '-f', and the output directory via '-o'. The analysis takes about 10 minutes and produces QC report files in the specified output directory; per-nucleotide error profiles used in reporting can also be derived with pysamstats and variant calling/consensus generation with bcftools v1.15. Validate that the output directory (e.g. /src/out) exists and contains the Mana QC report files.

## Examples

```
docker run -v ${PWD}:/src -i -t mana python3 mana.py --mrna -b /src/alignment.bam -f /src/file.fasta -o /src/out
```

## Evaluation signals

- The output directory specified by '-o' exists and contains the QC report files produced by Mana after the ~10-minute run
- The input BAM is sorted and indexed (SAMtools-generated), otherwise Mana cannot consume it
- Reported sequence identity matches the reference with full and homogeneous coverage across the entire mRNA vaccine length
- Reported 3'-poly(A) tail length matches the template-encoded expected value (e.g. 126nt for the reference eGFP mRNA)
- Docker container runs 'python3 mana.py' without dependency errors, confirming SAMtools, BCFtools, Pysam, and bedtools are resolved via the pre-built image

## Limitations

- Building the Docker image yourself takes >= 20 minutes and is not recommended; use the pre-built scchess/mana image instead
- Underlying study data are predominantly proof of concept, ranging from n = 1 to n = 4, with no statistical method used to predetermine sample size
- cDNA sequencing was found more reliable than direct RNA sequencing, so QC conclusions are strongest for cDNA-derived alignments
- Files must be mounted correctly into Docker with the '-v' option; incorrect mounting means Mana cannot see the input BAM or reference FASTA
