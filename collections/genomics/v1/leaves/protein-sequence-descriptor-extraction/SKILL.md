# protein-sequence-descriptor-extraction

## Summary

Encode protein sequences into the four multi-view descriptor spaces used by iDBP-DEP — DDE (dipeptide deviation from expected mean), PSSM-DBT, PSSM-DWT and NMBAC — which together yield 3240-dimension feature vectors for DNA-binding protein prediction and per-descriptor ablation.

## When to use

Use when you need per-descriptor protein feature matrices (.mat workspaces for DDE, PSSM-DBT, PSSM-DWT, NMBAC) from FASTA sequences plus PSI-BLAST PSSM profiles, e.g. for ablation or downstream SVM-RFE+CBR selection.

## When NOT to use

- The per-descriptor .mat feature tables already exist in the repository's Data/*/Feature Data directories — load them instead of re-extracting
- You only have raw sequences without PSI-BLAST PSSM profiles and cannot run PSI-BLAST against nr, since PSSM-DBT and PSSM-DWT require evolutionary profiles
- The goal is classifier training or evaluation (before_FS.m, train_1075.m) rather than descriptor generation

## Inputs

- Protein FASTA sequences (PDB1075: 525 DBPs / 550 non-DBPs; PDB594: 297/297; PDB186: 93/93)
- PSSM profiles generated by PSI-BLAST against the nr database (e.g. PDB1075_seqs_PSSM, PDB594_seqs_PSSM)
- Physicochemical property matrix phy_6.mat for NMBAC

## Outputs

- Per-descriptor .mat feature files, e.g. DDE.mat, PSSM_DBT.mat, PSSM_DWT.mat, feature_NMBAC.mat per dataset
- Per-dataset MATLAB workspaces (e.g. PDB594_workspace/DDE594_workspace.mat, PSSM_DBT_594_workspace.mat)
- Combined 3240-dimension feature vector per protein for SVM input

## How to apply

First generate PSSM profiles by searching each target protein against the non-redundant (nr) database with PSI-BLAST. Then run each descriptor extractor from ~/Code/feature_Extract: DDE via DDE.py on the sequence file; PSSM-DBT (getDBT.m) with parameter T=3; PSSM-DWT (getDWT.m) with 4-scale decomposition computing maximum, minimum, mean and standard deviation of approximation and detailed coefficients; and NMBAC (BAC.m with phy_6.mat physicochemical properties) with nlag=30, where T and nlag were fixed by 10-fold cross-validation. The four outputs are per-descriptor .mat files (e.g. DDE594.mat, PSSM_DBT_594.mat, PSSM_DWT_594.mat, feature_NMBAC_594.mat) and combined 3240-dimension vectors (DDE 400 + PSSM-DBT 1600 + PSSM-DWT 1040 + NMBAC 200). Keep each descriptor space separate if the downstream goal is per-descriptor feature selection with SVM-RFE+CBR before SVM classification.

## Related tools

- **PSI-BLAST** (Generates the PSSM/PSFM evolutionary profiles that are the input for the PSSM-DBT and PSSM-DWT descriptors)
- **LIBSVM** (Downstream consumer of the extracted descriptors: SVM with radial basis function kernel (C=1, gamma=0.03125) trained on the feature subsets)

## Examples

```
python Code/feature_Extract/DDE/DDE.py  # then MATLAB: getDBT.m, getDWT.m, BAC.m on the PSSM profiles to build the .mat workspaces
```

## Evaluation signals

- Combined feature dimension must equal 3240 (DDE 400 + PSSM-DBT 1600 with T=3 + PSSM-DWT 1040 with 4-scale DWT + NMBAC 200 with nlag=30)
- Per-dataset descriptor files named consistently with the README structure (e.g. DDE594.mat, PSSM_DBT_594.mat, PSSM_DWT_594.mat, feature_NMBAC_594.mat for PDB594)
- Row counts match dataset sizes: 1075 rows for PDB1075, 594 for PDB594, 186 for PDB186
- Downstream per-descriptor SVM (LIBSVM RBF, C=1, gamma=0.03125) Jackknife accuracy should reproduce the paper's individual-descriptor results, e.g. PSSM-DBT Acc 82.70%, MCC 0.654 on PDB1075
- Descriptor parameter settings must be T=3 (PSSM-DBT) and nlag=30 (NMBAC) as chosen by 10-fold cross-validation in the paper

## Limitations

- Descriptor extractors for PSSM-DBT, PSSM-DWT and NMBAC are MATLAB (.m) only; only DDE is provided in Python (DDE.py)
- PSSM-DBT/PSSM-DWT depend on PSI-BLAST runs against nr, so profiles are not reproducible byte-for-byte as the nr database evolves
- The repository README contains conflicting merge markers (two divergent branches), and no version numbers are stated for LIBSVM or PSI-BLAST
