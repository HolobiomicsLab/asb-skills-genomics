# chopSeq read fragmentation and orientation correction

## Summary

Fragment INC-Seq consensus reads and correct their orientation with chopSeq, the first step of the NanoAmpli-Seq workflow, to prepare noisy nanopore amplicon reads for de novo clustering and consensus calling.

## When to use

Use when processing INC-Seq consensus reads from Oxford Nanopore 2D/1D2 amplicon sequencing that need fragmentation and read orientation correction before de novo clustering.

## When NOT to use

- Input reads are already short amplicon fragments rather than long INC-Seq consensus reads
- Goal is classification-only taxonomic assignment rather than de novo full-length 16S rRNA gene consensus generation
- Workflow relies on reference-based clustering of reads against SILVA or a custom database, which NanoAmpli-Seq explicitly avoids

## Inputs

- INC-Seq consensus reads (nanopore amplicon data, e.g. 2D or 1D2 reads from the ONT MinION platform)
- Ladder replicate INC-Seq read data from Li et al. (available at github.com/umerijaz/nanopore)

## Outputs

- Fragmented, orientation-corrected reads suitable for nanoClust de novo clustering and within-cluster consensus calling

## How to apply

Run chopSeq on the INC-Seq consensus reads generated by mapping raw, noisy nanopore reads rolling-circle style, as developed in the NanoAmpli-Seq workflow of Calus, Ijaz and Pinto. chopSeq fragments the long consensus reads and corrects read orientation so that all fragments share a consistent direction, since nanopore consensus reads carry mixed orientations and residual errors dominated by deletions in homopolymer regions. The fragmented, orientation-corrected reads are then passed to nanoClust for read partitioning-based de novo clustering and within-cluster consensus calling to obtain full-length 16S rRNA gene sequences without any reference database. This design deliberately avoids reference-based mapping, which is error-prone on raw nanopore reads and discards reads from organisms absent from the reference. Validate downstream by checking consensus accuracies against the expected ~99.5% average reported for 2D and 1D2 sequencing on tested mock communities.

## Evaluation signals

- Average consensus sequence accuracy of approximately 99.5% for 2D and 1D2 sequencing on tested mock communities
- On the R7-chemistry Ladder replicate data of Li et al., reproduced accuracy of ~99.5% average with the Fusobacterium OTU at approximately 98.75%, versus the 97-98% INC-Seq baseline
- nanoClust partitions the 10-organism community into its 8 theoretical OTUs
- Residual errors in the corrected sequences are almost entirely deletions in homopolymer regions
- Community diversity estimates match the expected mock community composition

## Limitations

- Nearly all residual errors in NanoAmpli-Seq sequences originate from deletions in homopolymer regions, so accuracy may drop on homopolymer-rich targets unless homopolymer-aware base calling or error correction is used
- Accuracy comparable to short-read platforms may only be reachable with homopolymer-aware base calling or error correction
- The skill was validated on mock communities and previously published R7-chemistry data; performance on other chemistries or complex communities may differ
