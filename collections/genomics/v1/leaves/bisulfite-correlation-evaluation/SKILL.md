# bisulfite-correlation-evaluation

## Summary

Evaluate Nanopore-derived 5mC methylation calls (DeepSignal-plant per-site methylation frequencies) against bisulfite sequencing replicates by computing context-wise per-site Pearson correlations (CG/CHG/CHH), with coverage and methylation-frequency filters applied to both data sources before comparison.

## When to use

Use when per-read Nanopore 5mC probabilities for plant cytosines (CG/CHG/CHH) must be validated against bisulfite sequencing, e.g. after retraining or comparing DeepSignal-plant vs Megalodon.

## When NOT to use

- The task is training-label generation, not model evaluation — use the high-confidence site criteria (≥5 reads, ≥0.9 or zero methylation frequency) to build positive/negative training samples instead
- No matched bisulfite sequencing data exist for the sample, since the Pearson correlation is defined against bisulfite methylation levels
- The tool under evaluation does not output per-read modification probabilities that can be aggregated into per-site frequencies (e.g. pure signal-distribution tests like Tombo with different semantics)

## Inputs

- DeepSignal-plant call_mods output (per-read 5mC probabilities from deepsignal_plant call_mods on re-squiggled R9.4 FAST5 features)
- Per-site methylation frequency table generated by deepsignal_plant call_freq (optionally --bed --sort bedMethyl output)
- Bisulfite sequencing replicate methylation calls for the same reference genome (e.g. TAIR10 GCF_000001735.4 for A. thaliana)

## Outputs

- Per-context (CG/CHG/CHH) per-site Pearson correlation values between Nanopore methylation frequencies and each bisulfite replicate (expected: CHG 0.8464→0.9122, CHH 0.3696→0.7840 after balancing/denoising)
- RMSE and read-level accuracy metrics for tool-to-tool comparisons (reference values: CHG RMSE 0.1355, CG read-level accuracy 0.9257 for B. nigra)
- Filtered cytosine site set used for evaluation (≥5 mapped Nanopore reads, ≥10 mapped bisulfite reads)

## How to apply

Aggregate DeepSignal-plant per-read modification probabilities into per-site methylation frequencies with call_freq, then restrict evaluation sites by applying filters on both data sources: cytosines must have at least 5 mapped Nanopore reads and at least 10 mapped bisulfite reads (the B. nigra evaluation criterion). For each context (CG, CHG, CHH), compute per-site Pearson correlations between Nanopore methylation frequencies and each of the three bisulfite replicates. To judge training-set improvements, compare the correlations between models trained on randomly subsampled baseline data (capped at 20 million samples, half positive/half negative, bisulfite labels: methylated ≥5 reads and ≥0.9 methylation frequency, unmethylated ≥5 reads and zero frequency) versus the iteratively denoised set (I=10, R=3, E=3; remove positive samples with mean predicted methylation probability <0.5). Additionally report RMSE and read-level accuracy when comparing against other tools such as Megalodon.

- **DeepSignal-plant** (Produces per-read 5mC probabilities (call_mods) and per-site methylation frequencies (call_freq) that are the Nanopore side of the correlation) — https://github.com/PengNi/deepsignal-plant
- **Tombo** (Re-squiggles raw FAST5 signals against the genome reference (v1.5.1, RawGenomeCorrected_000 group) before feature extraction for modification calling) — https://github.com/nanoporetech/tombo

- **Megalodon** (Comparator tool whose modified-base calls are evaluated with the same site filters and per-context Pearson correlation/RMSE/read-level accuracy metrics)

## Examples

```
deepsignal_plant call_freq --input_path call_mods.tsv --bed --sort; # then correlate per-site frequencies vs bisulfite for cytosines with >=5 ONT and >=10 BS-seq reads
```

## Evaluation signals

- The denoised model must raise per-site Pearson correlation from 0.8464 to 0.9122 for CHG and from 0.3696 to 0.7840 for CHH (Fig. 1d reproduction)
- For tool comparison, recomputed context-wise metrics must match reported values (e.g. CHG RMSE 0.1355 and CG read-level accuracy 0.9257 for B. nigra) within a small tolerance
- Every cytosine in the evaluated set must satisfy ≥5 mapped Nanopore reads AND ≥10 mapped bisulfite reads
- Correlations should be computed separately for each of the three contexts and for each of the three bisulfite replicates, never pooled blindly
- Methylation frequency table should contain methylated-read counts and total mapped-read counts per cytosine as output by call_freq

## Limitations

- Training/evaluation gold standard is bisulfite sequencing, so performance is bounded by bisulfite quality (incomplete conversion, DNA degradation, no coverage in repetitive regions)
- For A. thaliana CHG/CHH, high-confidence methylated sites use a union of three bisulfite replicates (lower stringency), introducing potential label noise
- The paper defers some details (Megalodon training in Supplementary Note 5; runtime/memory in Supplementary Note 4/Table 12) and gives no accession numbers for the Nanopore/bisulfite reads used
