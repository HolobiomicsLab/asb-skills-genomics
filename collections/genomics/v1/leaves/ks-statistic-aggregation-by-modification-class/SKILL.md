# ks-statistic-aggregation-by-modification-class

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Aggregate per-position Tombo KS statistics by rRNA modification class (Nm, Ψ, base) and compute median KS profiles centered on known modification sites for nanopore current and dwell-time signals, revealing class-specific signatures such as a secondary dwell-time peak ~10 nt downstream (3') for Nm and Ψ.

## When to use

Use when nanopore direct RNA KS statistics from tombo model_sample_compare are available for rRNAs with annotated modification positions and the goal is class-level (Nm vs Ψ vs base) aggregate current/dwell-time KS profiles.

## When NOT to use

- Input reads are not yet resquiggled single fast5 files or no IVT control comparison exists — run tombo resquiggle and model_sample_compare first
- The RNA lacks annotated modification positions/classes (Nm, Ψ, base), so class-level aggregation and alignment by known modification position are impossible
- The question is single-molecule per-read visualization rather than aggregate class-level profile construction

## Inputs

- Resquiggled single fast5 directories for modified and IVT control samples (tombo-processed)
- FASTA reference file of the rRNA sequences
- Per-position KS statistics file from tombo detect_modifications model_sample_compare
- Per-read signal .npy arrays for current and dwell time generated by extract_array.py
- Annotated rRNA modification sites with class labels (Nm, pseudouridine, base)

## Outputs

- Per-class median KS statistic profiles centered on modification sites for nanopore current
- Per-class median KS statistic profiles for dwell time
- Profile plots confirming constriction peak (position 0) and ~10 nt 3'-displaced secondary dwell-time peaks for Nm and Ψ

## How to apply

Run tombo detect_modifications model_sample_compare on resquiggled single-fast5 directories (modified vs IVT control) with --minimum-test-reads 100 and --multiprocess-region-size 250 to obtain per-position KS statistics, then use extract_array.py with --fa, --f5, --sort-reads, and --current/--dwell/--stdev to write per-read signal .npy arrays. Align per-position KS statistics to annotated rRNA modification sites and group them by modification class (Nm, Ψ, base) for E. coli and S. cerevisiae rRNAs. For each class, compute the median KS statistic profile centered on the modified nucleotide for both current and dwell-time signals. Judge success by the expected signature: the median current profile shows a single peak at the constriction (relative position 0) at the modification site, while the median dwell-time profile for Nm and Ψ shows a primary constriction peak plus a secondary peak displaced approximately 10 nt in the 3' direction; base modifications should lack the secondary peak, and Nm typically shows a larger median KS statistic than Ψ.

## Examples

```
python extract_array.py --fa reference.fa --f5 modified_single_fast5/ --out dwell.npy --rna-name rrna --sort-reads --dwell
```

## Evaluation signals

- Median current profile shows a single peak at relative position 0 (nanopore constriction) centered on the modified nucleotide
- Median dwell-time profile for Nm and Ψ classes shows a primary peak plus a secondary peak approximately 10 nt in the 3' direction
- Base modification classes do not show the secondary dwell-time peak
- Nm class exhibits a larger median KS statistic than Ψ
- Per-read extraction succeeded only when --minimum-test-reads 100 threshold was met and arrays were written as sorted .npy files per signal type

## Limitations

- Signal discrimination remains a function of kmer sequence context and raw-current alignment quality
- Modification identification without an IVT control is not supported, as training sets of known modifications in all possible kmer sequence contexts do not yet exist
- Identified rRNA modification positions are accurate to within ±2 nt of known sites, limiting per-position precision
