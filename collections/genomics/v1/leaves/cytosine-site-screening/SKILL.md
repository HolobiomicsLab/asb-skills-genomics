# cytosine-site-screening

## Summary

Screens cytosine sites within segmental-duplication repeat pairs for differential methylation in the DeepSignal-plant analysis: repeat pairs are found by whole-genome self-alignment with MUMmer (length >100, identity >0.99, at least one cytosine), and a cytosine is called differentially methylated when |rmet1−rmet2| >= 0.5.

## When to use

Use when you have a genome reference (e.g. GCF_000001735.4_TAIR10.1_genomic.fna for A. thaliana), Nanopore-derived per-site methylation frequencies, and need to identify repeat pairs and differentially methylated cytosines between duplicated regions.

## When NOT to use

- Your goal is per-read methylation-state calling from raw Nanopore signals rather than site-level screening within repeat pairs — use deepsignal_plant call_mods/tombo resquiggle instead.
- Your methylation data come from short-read bisulfite sequencing and cannot cover the highly repetitive regions this screen targets.
- You only have a single methylation condition (rmet1/rmet2 comparison is not defined).

## Inputs

- Genome reference FASTA (e.g. GCF_000001735.4_TAIR10.1_genomic.fna from NCBI; IRGSP-1.0 / GCA_001433935.1 for O. sativa from EnsemblPlants)
- MUMmer whole-genome self-alignment output of the reference
- Per-site methylation frequency table generated by deepsignal_plant call_freq from the call_mods file
- In-house Python scripts for parsing alignments and filtering repeat pairs

## Outputs

- Tab-delimited repeat_pairs.tsv listing filtered repeat pairs (length >100, identity >0.99, at least one cytosine)
- Per-cytosine differential-methylation calls (|rmet1−rmet2| >= 0.5)
- Per-repeat-pair differential-methylation status (>=10% of cytosines differentially methylated)

## How to apply

First self-align the genome reference with MUMmer (nucmer/promer) and parse the alignment with Python scripts to select region pairs with length >100 and identity score >0.99 as repeat pairs. Retain only repeat pairs containing at least one cytosine and write them to a tab-delimited repeat_pairs.tsv. Per-site methylation frequencies come from the DeepSignal-plant pipeline (call_mods followed by call_freq). A cytosine in a repeat pair is differentially methylated if |rmet1−rmet2| >= 0.5, and a repeat pair is considered differentially methylated if >=10% of its cytosines are differentially methylated.

## Related tools

- **MUMmer** (whole-genome self-alignment (nucmer/promer) of the reference FASTA to produce candidate repeat regions)
- **DeepSignal-plant** (produces the per-site methylation frequencies (call_mods + call_freq) that supply rmet1/rmet2 for the differential screen) — https://github.com/PengNi/deepsignal-plant
- **Python3** (in-house scripts parse the MUMmer alignment and apply the length/identity/cytosine filters) — https://github.com/PengNi/deepsignal-plant
- **Tombo** (re-squiggles raw Nanopore signals to reference bases upstream of methylation calling) — https://github.com/nanoporetech/tombo

## Examples

```
nucmer GCF_000001735.4_TAIR10.1_genomic.fna GCF_000001735.4_TAIR10.1_genomic.fna; deepsignal_plant call_mods --input_path fast5s.C.features.tsv; deepsignal_plant call_freq --input_path call_mods.tsv --out_file freq.tsv
```

## Evaluation signals

- Every output repeat pair satisfies alignment length >100 and identity score >0.99
- Every retained repeat pair contains at least one cytosine in the paired regions
- Each differentially methylated cytosine satisfies |rmet1−rmet2| >= 0.5
- A repeat pair is flagged differentially methylated only if >=10% of its cytosines are differentially methylated
- repeat_pairs.tsv is a valid tab-delimited table and downstream differential-methylation counts reconcile against it

## Limitations

- Repeat-pair selection relies on in-house Python scripts with no stated deposition, limiting reproducibility
- Key details of the repeat-pair/differential-methylation analysis are deferred to supplementary materials not included in the main text
- Screening requires cytosines covered by methylation calls; the gold-standard training of DeepSignal-plant depends on bisulfite sequencing quality
