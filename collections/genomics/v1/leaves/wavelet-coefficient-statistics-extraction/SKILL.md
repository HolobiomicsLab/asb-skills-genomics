# wavelet-coefficient-statistics-extraction

## Summary

Encodes a protein's PSSM evolutionary profile as 20 discrete signals and compresses each via 4-scale Discrete Wavelet Transform (DWT), yielding the 1040-dimension PSSM-DWT descriptor used in the iDBP-DEP DNA-binding protein predictor.

## When to use

Use when raw PSI-BLAST PSSM profiles of variable length (N x 20) must be converted into fixed-length evolutionary feature vectors for sequence-level protein classification such as DNA-binding protein detection.

## When NOT to use

- The input is already a fixed-length feature table (e.g. precomputed DDE, NMBAC or PSSM-DBT .mat files) rather than variable-length PSSM profiles
- The analysis requires residue-level (position-resolved) rather than sequence-level features, since DWT coefficient statistics discard positional detail
- No PSSM profile can be generated (e.g. no PSI-BLAST or nr database available), since the whole descriptor depends on evolutionary profiles

## Inputs

- PSI-BLAST PSSM profile matrices (N x 20) per protein sequence, generated against the nr database
- Protein sequences from benchmark datasets PDB1075, PDB594, PDB186

## Outputs

- 1040-dimension PSSM-DWT feature vector per protein
- Serialized MATLAB .mat feature files (e.g. PSSM_DWT.mat, PSSM_DWT_594.mat, PSSM_DWT_186.mat) contributing to the 3240-dimension combined feature vector

## How to apply

Load each N x 20 PSSM profile generated by PSI-BLAST (searched against the nr database) and treat each of the 20 amino-acid columns as a discrete signal of length N, removing noise components via DWT. Decompose each signal 4 times with low-pass/high-pass filters and down-sampling; at each scale compute the maximum, minimum, mean and standard deviation of both approximation and detailed coefficients (32 features per signal). From the more important approximation coefficients, extract the top five DCT coefficients for an additional 20 features per signal, giving 52 features per signal. Concatenate across all 20 signals to obtain the 20 x 52 = 1040-dimension PSSM-DWT vector and serialize it as a MATLAB .mat workspace file (e.g. PSSM_DWT_1075.mat); combine with PSSM-DBT, DDE and NMBAC into the full 3240-dimension vector.

## Related tools

- **PSI-BLAST** (Generates the N x 20 PSSM profiles from the nr database that serve as the raw input signals for DWT encoding)
- **iDBP-DEP (PSSM-DWT MATLAB code: EstraggoConDWT.m, getDWT.m)** (Implements the 4-scale DWT decomposition, coefficient statistics and DCT extraction producing the 1040-dimension descriptor) — https://githup.com/Zll-codeside/iDBP-DEP

## Evaluation signals

- The resulting per-protein feature matrix contains exactly 1040 dimensions (20 amino-acid signals x 52 features each)
- Each signal contributes 32 DWT coefficient statistics (max, min, mean, standard deviation of approximation and detailed coefficients at 4 scales) plus 20 DCT coefficients from approximation coefficients
- Decomposition was iterated exactly 4 times, matching the paper's stated parameterization
- Serialized output is a MATLAB .mat workspace file consistent with the repo's PSSM_DWT*.mat artifacts (e.g. PSSM_DWT_186.mat, PSSM_DWT_594.mat)
- Combined with NMBAC (200-d), DDE and PSSM-DBT descriptors, the total feature vector dimension equals 3240

## Limitations

- The PSSM input depends on PSI-BLAST search conditions against nr; no PSI-BLAST version is stated in the article, so reproducibility of profiles may vary
- DWT compression deliberately removes signal noise components, which discards some fine-grained positional evolutionary information
- Feature files in the repo are precomputed for the specific benchmark datasets (PDB1075, PDB594, PDB186); new datasets require regenerating PSSM profiles and re-running DWT extraction
