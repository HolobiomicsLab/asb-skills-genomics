# long-read-transcript-alignment

## Summary

Align PacBio Iso-seq full-length transcript (CCS) reads to a reference genome using TAGET's TransAnnot.py wrapper, which orchestrates Minimap2 and/or HISAT2 alignments against hg38 with samtools post-processing, producing annotated BED, junction, and classification files that feed TAGET's annotation, quantification, and fusion-detection components.

## When to use

Use when input is PacBio Iso-seq full-length transcript FASTA (CCS reads) that must be aligned to a reference genome (e.g., hg38.fa) with splice-aware annotation of transcripts, junctions, and read classifications.

## When NOT to use

- Input reads are short-read RNA-seq rather than long-read Iso-seq full-length transcript FASTA (HISAT2 short-read support uses defaults of 100 bp read length / 80 bp overlap, a different context)
- The goal is de novo transcript reconstruction (e.g., with ESPRESSO, FLAIR, StringTie2, IsoQuant) rather than alignment-and-annotation of full-length reads
- No reference genome or annotation GTF is available, since TransAnnot requires hg38-style genome FASTA plus Ensembl GTF and prebuilt indices

## Inputs

- Full-length transcript FASTA (PacBio Iso-seq CCS reads)
- Reference genome FASTA (hg38.fa)
- Ensembl GTF annotation (hg38.ensembl.gtf) and its pickle generated by gtf_db_make.py
- HISAT2 index (hisat2-build) and/or Minimap2 index of the reference genome
- TransAnnot.Config with software paths, index paths, process number, and sample prefix

## Outputs

- {sample_id}.annot.bed (bed format with annotated genes)
- {sample_id}.annot.stat (per-read classification, subtype, gene/transcript annotation, coordinates)
- {sample_id}.annot.junction (splice junction file)
- {sample_id}.annot.db.pickle (visualization input)
- {sample_id}.annot.cluster.gene / .cluster.transcript / .cluster.reads
- {sample_id}.annot.multiAnno (multi-annotation transcripts)
- Minimap2- and HISAT2-generated bed files used for fusion detection

## How to apply

Run `python TransAnnot.py -f [fasta] -g [genome fasta] -o [output directory] -a [annot gtf] -p [process] --use_minimap2 1 --use_hisat2 [hisat2 index]` (or via TransAnnot.Config), requiring at least one of HISAT2/Minimap2/GMAP plus samtools, python3 with rpy2/pandas/numpy, and R>=3.3. Build reference indices first with hisat2-build and/or minimap2 indexing of hg38.fa, and generate the GTF pickle via `python gtf_db_make.py hg38.ensembl.gtf hg38.ensembl.v20200306.1.pickle` from an Ensembl GTF. Use at least 8 processes; runtime is under 1 hour on an 8-core Linux server for a demo dataset. HISAT2 parameters in TransAnnot.Config default to read length 100 and read overlap 80, with a minimum read length of 30. Collect per-aligner splice junction files ({sample_id}.annot.junction) and alignments ({sample_id}.annot.bed, minimap2/hisat2 .bed) as downstream inputs for annotation, quantification (--tpm), and gene fusion detection (TAGET_fusion_2-3_ajust.r).

## Related tools

- **TAGET** (Toolkit whose TransAnnot.py wraps the alignment workflow and produces annotated/junction outputs) — https://github.com/XiDsLab/TAGET
- **Minimap2** (Long-read aligner of Iso-seq transcripts to the reference genome (USE_MINIMAP2=1), producing minimap2 bed files)
- **HISAT2** (Splice-aware aligner of full-length transcripts (USE_HISAT2=1, index via hisat2-build), producing hisat2 bed files)
- **GMAP** (Optional alternative aligner (USE_GMAP=1) with index generated by gmap_build)
- **samtools** (SAM/BAM post-processing inside the TAGET alignment pipeline)

## Examples

```
python TransAnnot.py -f [fasta] -g hg38.fa -o ./output -a hg38.ensembl.gtf -p 8 --use_minimap2 1 --use_hisat2 [hisat2 index]
```

## Evaluation signals

- Expected output files all exist per sample: {sample_id}.annot.stat, .annot.bed, .annot.junction, .annot.db.pickle, .annot.multiAnno
- Runtime sanity: demo completes in under 1 hour on an 8-core Linux server
- Junction quality check: ~99.3% of TAGET-predicted junctions should be supported by at least two short reads or the reference database (75.2% of novel junctions), versus 99.1%/48.5% for minimap2 alone
- Alignment bed files for minimap2 and HISAT2 (e.g., {i}.fa.minimap2.bed, {i}.fa.hisat2.bed) are present and usable by TAGET_fusion_2-3_ajust.r
- Read classifications in {sample_id}.annot.stat fall within the defined categories (FSM, ISM, NIC, NNC, GENIC, INTERGENIC, FUSION, UNKNOWN)

## Limitations

- Requires Linux CentOS environment with at least one of HISAT2/Minimap2/GMAP, samtools, python3 (rpy2, pandas, numpy), and R>=3.3 with stringr/optparse/DEGseq
- HISAT2 and Minimap2 indices of the reference genome must be built beforehand, and the GTF pickle must be generated via gtf_db_make.py
- Iso-seq CCS-read clusters containing only one read (~80% of CCS reads) are typically filtered upstream due to lower quality, limiting effective coverage and detected genes
- Multi-annotated transcripts appear in {sample_id}.annot.multiAnno, so read-to-transcript assignment can be ambiguous
