# scrna-seq-5p-cdna-library-processing

## Summary

Processing of 5'-anchored 10x Genomics single-cell whole-transcriptome cDNA libraries with long-read (ONT/PacBio) sequencing via the nanoranger pipeline, to detect lineage-defining features such as SNVs, fusion genes, isoforms, and CAR/TCR sequences per cell.

## When to use

Use when the input is a long-read FASTQ from a 5'-anchored 10x Genomics scRNA-seq whole-transcriptome cDNA library (or targeted amplicons thereof) and per-cell genotypes/fusions/isoforms must be called with cell barcodes and UMIs preserved.

## When NOT to use

- Input is already a processed feature-cell count matrix or processed 10x short-read output rather than long-read cDNA/amplicon FASTQ
- Target loci are distant from the 5' end of long (>4 kB), lowly expressed transcripts, where 5'-anchored capture underrepresents the region and genotyping cannot be rescued by deeper sequencing
- Short-read sequencing suffices for the variant class, e.g., point mutations covered by small primer panels without structural variants

## Inputs

- Long-read FASTQ from a 10x Genomics 5' whole-transcriptome cDNA library (ONT or PacBio)
- Amplicon FASTQ from targeted amplification of 10x cDNA libraries
- Reference transcripts spanning fusion junctions or target loci

## Outputs

- Aligned long-read records with 10x cell barcode (CB) and UMI tags per read
- Fusion call tables (e.g., fusion_calls.tsv) with fusion gene, cell barcode, and UMI fields
- Per-cell counts and fractions of cells positive for fusion transcripts or other lineage-defining features

## How to apply

Start from intermediate single-cell cDNA libraries generated by 10x Genomics 5' whole-transcriptome chemistry and sequenced on Oxford Nanopore Technologies or Pacific Biosciences devices; input can be whole-transcriptome libraries or amplicons obtained through targeted amplification with limited primer sets. Run nanoranger in the mode matching the library (e.g., 5p10XGEX fusion mode for fusion detection), aligning long reads to reference transcripts spanning the targets of interest while retaining chimeric reads together with their 10x cell barcode and UMI sequences. For fusion calling, parse chimeric alignments that span the fusion breakpoint (e.g., BCR::ABL1 or RUNX1::RUNX1T1) and process with the downstream fusion_gene.py script to deduplicate barcode-UMI pairs per cell and tabulate fusion-supporting reads. Note that optimal targets are loci close to the 5' end of highly expressed genes with transcript lengths shorter than 4 kB, since 5'-anchored capture biases representation toward the transcript 5' end.

## Evaluation signals

- A fusion call table (fusion_calls.tsv) exists and contains the expected entries (e.g., BCR::ABL1 and RUNX1::RUNX1T1) with cell barcode and UMI fields
- Fractions of fusion-positive cells fall in the reported range, e.g., ~2.7% (124 cells) BCR::ABL1+ among K562 and ~3.9% (88 cells) RUNX1::RUNX1T1+ among Kasumi-1 in the mixing library
- Cell barcodes are 10x whitelist-consistent and UMI duplicates are collapsed (Levenshtein distance ≤3 via starcode in nanoranger.R) before counting per-cell positives
- Knee plot cell-calling cutoff in nanoranger.R yields a plausible number of cells for the library
- Called chimeric reads actually span the fusion breakpoint rather than an internal alignment artifact

## Limitations

- Fusion breakpoints distant from the 5' end are detected in only a small fraction of cells (2.7% for BCR::ABL1, 3.9% for RUNX1::RUNX1T1 in the K562/Kasumi-1 mixing library), reflecting the 5'-anchored capture design
- The genotyping ceiling is set by low, incomplete transcript representation, including absence of longer variants, and cannot be overcome merely through amplicon optimization or deeper sequencing
- UMIs in 10x libraries have no whitelist, so sequencing-error UMIs must be collapsed by distance-based grouping rather than corrected against a known set
