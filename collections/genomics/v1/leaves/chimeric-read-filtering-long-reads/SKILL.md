# chimeric-read-filtering-long-reads

## Summary

Detection and removal of chimeric PacBio Iso-Seq reads using isoseq3 refine, the ISOSEQ REFINE step of the nf-core/isoseq pipeline, applied to primer-trimmed CCS reads to yield FLNC BAM output.

## When to use

Use when processing PacBio subread BAMs through the nf-core/isoseq pipeline and primer removal (LIMA) is done: CCS reads must be screened for chimeric sequences before FLNC reads are converted and polyA-trimmed.

## When NOT to use

- Input reads are raw subreads that have not yet been converted to CCS or primer-trimmed by LIMA — run ccs and LIMA first
- The analysis goal is splice-aware genome alignment (minimap2/uLTRA) or transcriptome collapsing rather than FLNC read cleaning
- Reads are short-read or non-PacBio transcriptomic data outside the Iso-Seq subread-to-FLNC preprocessing context

## Inputs

- Primer-trimmed circular consensus sequence (CCS) reads in BAM format (output of LIMA)
- CCS reads generated by PacBio ccs from input subread BAM files

## Outputs

- FLNC BAM file containing full-length non-chimeric reads ready for bamtools convert (BAM to FASTA) and TAMA polyA cleanup

## How to apply

First run PacBio ccs on subread BAMs to generate Circular Consensus Sequences, then run LIMA to select reads containing valid primer pairs and remove the primers. Apply isoseq3 refine (ISOSEQ REFINE) to the primer-trimmed reads so that chimeric sequences are detected and discarded; the retained reads constitute the FLNC BAM output. This step is positioned after primer removal and before bamtools conversion to FASTA and TAMA (gstama_polyacleanup) polyA tail trimming in the workflow, so its output feeds directly into the polyA cleanup stage. Correctness is judged by confirming the FLNC reads are free of chimeras and primers and that only valid primer-pair sequences are retained downstream.

- **nf-core/isoseq** (Nextflow pipeline that orchestrates the ISOSEQ REFINE chimeric-read-removal step within the subread preprocessing stage) — https://github.com/nf-core/isoseq

## Evaluation signals

- Confirm the FLNC BAM output exists and contains no chimeric reads per the isoseq3 refine step
- Confirm only reads with valid primer pairs were retained upstream (LIMA) so chimera filtering operates on the correct read set
- Verify the FLNC BAM feeds successfully into bamtools convert and TAMA polyacleanup, producing chunked polyA-tail-free FASTA files
- Check that discarded chimeras are reported/removed and the retained FLNC read set is consistent between refine and downstream steps

## Limitations

- No software version numbers are recorded for the tools in this changelog section, which is a reproducibility gap when pinning isoseq3/ISOSEQ REFINE versions
- Chimera removal happens strictly after CCS generation and LIMA primer removal; running refine on untrimmed or non-CCS input is not covered by the pipeline description
