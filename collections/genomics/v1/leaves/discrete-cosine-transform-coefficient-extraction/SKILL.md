# discrete-cosine-transform-coefficient-extraction

## Summary

A feature-engineering step in the iDBP-DEP pipeline that extracts the top five Discrete Cosine Transform (DCT) coefficients from DWT approximation coefficients of each PSSM signal, adding 20 features per amino-acid signal to the fixed-length PSSM-DWT descriptor (1040-d total). This compresses position-resolved evolutionary information into compact, classifiable numerical features.

## When to use

Use when a variable-length N x 20 PSSM profile must be compressed into fixed-length descriptors for an SVM classifier, specifically after 4-scale DWT decomposition to add DCT-coefficient features from approximation components.

## When NOT to use

- Input is already a fixed-length feature table (e.g. the provided .mat feature files DDE/PSSM_DBT/NMBAC), since DCT extraction targets raw variable-length PSSM matrices
- When only sequence-level composition descriptors are needed (e.g. DDE dipeptide composition), with no evolutionary profile available

## Inputs

- N x 20 PSSM profile per protein sequence (generated by PSI-BLAST against nr, 3 iterations, e-value 0.001)
- DWT approximation coefficients per amino-acid signal (from 4-scale decomposition)

## Outputs

- 20 DCT-coefficient features per amino-acid signal (top 5 DCT coefficients x 20 signals)
- 1040-dimension PSSM-DWT feature vector per protein (20 x 52 features)
- MATLAB .mat workspace file (e.g. PSSM_DWT_186.mat, PSSM_DWT_594.mat, PSSM_DWT.mat)

## How to apply

First generate each protein's PSSM by searching the nr database with PSI-BLAST (3 iterations, e-value 0.001), then treat the N x 20 PSSM matrix as 20 discrete signals of length N. Apply Discrete Wavelet Transformation, iteratively decomposing approximation coefficients with low-pass/high-pass filters and down-sampling 4 times, computing max/min/mean/standard deviation of approximation and detailed coefficients at each scale (32 features per signal). From the more important approximation coefficients, additionally extract the top five discrete cosine transform coefficients, yielding 20 extra features per signal (52 per signal total). Concatenate the 52 features across all 20 amino-acid signals to obtain the 20 x 52 = 1040-dimension PSSM-DWT vector per protein, which is combined with DDE, PSSM-DBT and NMBAC (200-d) descriptors into a 3240-d feature vector and serialized as a MATLAB .mat workspace file.

## Related tools

- **PSI-BLAST** (Generates the N x 20 PSSM evolutionary profiles that the DWT/DCT descriptor is computed on, by searching the nr database (3 iterations, e-value 0.001))
- **iDBP-DEP MATLAB DWT code (getDWT.m / EstraggoConDWT.m / ExDWT_demo.txt)** (Implements the 4-scale DWT decomposition and extraction of the PSSM-DWT features, including the DCT coefficients from approximation coefficients) — https://githup.com/Zll-codeside/iDBP-DEP

## Examples

```
matlab -batch "run('Code/feature_Extract/PSSM-DWT/EstraggoConDWT.m')"  % computes 1040-d PSSM-DWT features incl. DCT coefficients -> PSSM_DWT_<dataset>.mat
```

## Evaluation signals

- Serialized PSSM-DWT feature matrix contains exactly 1040 feature dimensions per protein (20 signals x 52 features, of which 20 are DCT-derived)
- Each amino-acid signal contributes exactly 52 features: 32 from DWT coefficient statistics (max/min/mean/std of approximation and detailed coefficients at 4 scales) plus 20 from the top 5 DCT coefficients of approximation components
- Downsampling/decomposition is iterated exactly 4 times, matching the paper's stated 4-scale decomposition
- Per-protein PSSM-DWT features are serialized as MATLAB .mat workspace files (e.g. PSSM_DWT_186.mat) matching the repository's Data/<dataset>/Feature Data structure

## Limitations

- No software version numbers are stated for the tools in the article (only SVM implemented with LIBSVM package and SVM-RFE-CBR-v1.3 visible in the README file structure)
- The DCT extension is defined only over approximation coefficients; signal lengths shorter than 4 DWT decomposition scales may be problematic for very short protein sequences
- Feature validity was established in the context of DBP vs non-DBP discrimination with SVM (LIBSVM, RBF kernel, C=1, gamma=0.03125) plus SVM-RFE+CBR selection; performance on other tasks is untested in this study
