# codon-dependent-cleavage-composition-analysis

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Tests whether plant tncRNAs are generated by specific, codon-dependent tRNA cleavage rather than random degradation, by mapping cleavage positions of uniquely aligned reads onto mature tRNA annotations and computing nucleotide frequencies at the cleavage interface per isoacceptor.

## When to use

Use when small RNA-seq reads mapped to a tRNA artificial genome (tRNA + 50 nt flanks) need to be interrogated for whether tRNA cleavage positions show non-random, isoacceptor-specific nucleotide composition or a conserved interface motif such as AG::TGG.

## When NOT to use

- When the input reads are multi-mappers or were aligned allowing mismatches (the workflow requires uniquely mapping, 0-mismatch reads via bowtie1 '-v 0' to avoid base misidentification and false-negative inflation)
- When the goal is general tncRNA discovery/classification rather than interrogating the cleavage mechanism of already-identified tRFs
- When studying non-plant organisms: the AG::TGG motif and isoacceptor patterns were established across six angiosperms and existing tools were trained on human datasets

## Inputs

- FASTA of unique mapped tncRNA reads with per-read counts extracted from SAM flags 0 (forward) and 16 (reverse)
- Mature tRNA annotations with 50 bp 5' and 3' flanking regions
- bowtie1 mapping output (locus, location, read-length) linking tncRNA reads to progenitor mature tRNAs

## Outputs

- TSV table of cleavage-position counts and nucleotide compositions per tRNA isoacceptor
- RPM-normalized read counts per progenitor tRNA
- Detection report of the conserved tRF-5::tRNA interface motif (AG::TGG) at tRF-5 5'-ends

## How to apply

Load the unique mapped tncRNA reads (FASTA with per-read counts from SAM flags 0 and 16) and mature tRNA annotations with 50 bp 5'/3' flanks using pandas. Align reads to progenitor tRNAs with bowtie1 using '--norc -v 0 -m 50 --best --strata' to determine each read's cleavage position relative to the mature tRNA, classifying tRNA halves by cleavage in the 7 nt anticodon loop window (2 nt + 3 nt anticodon + 2 nt). Compute nucleotide frequencies at cleavage positions per isoacceptor (e.g. GluCTC, GlyTCC, LeuTAA, ProCGG) and normalize as RPM = reads mapped to progenitor tRNA / (total mapped reads / 1e6). Build local alignments of tncRNAs to their tRNAs of origin with biopython pairwise2 using scoring identical=1, non-identical=-1, gap-open=-1, gap-extend=-0.5, then inspect read-end/tRNA-interface bases for the conserved tRF-5::tRNA motif AG::TGG found in tRF-5s of 15–19 nt. Summarize cleavage-position counts and nucleotide compositions per isoacceptor into a TSV table demonstrating non-random cleavage.

## Evaluation signals

- Output TSV shows a non-uniform, codon-dependent nucleotide distribution at cleavage positions across isoacceptors (not uniform random cleavage)
- The AG::TGG interface motif is detected at the 5'-ends of tRF-5s of 15–19 nt, consistent with precise endoribonucleolytic cleavage
- Cleavage positions for tRNA halves fall within the 7 nt anticodon loop window (2 nt + 3 nt anticodon + 2 nt)
- RPM normalization is correct: reads mapped to progenitor tRNA divided by (total mapped reads / 1e6)
- Local alignments between tncRNAs and their tRNAs of origin correctly expose read-end/tRNA-interface bases for motif inspection

## Limitations

- Allowing a single mismatch in alignment may lead to base misidentification and inflation of false negatives, so 0-mismatch (-v 0) mapping is required for reliable composition analysis
- Conventional RNA-seq suffers from tRNA modification biases; tRNA-seq would be needed to fully characterize modified nucleosides influencing cleavage
- Only reads mapping exclusively to the artificial tRNA chromosomes (tRNA + 50 nt flanks) can be used, excluding ambiguous reads from non-tRNA regions
- The detailed mechanisms by which tRNA modifications regulate cleavage remain unclear, so compositional signals are correlative rather than mechanistic
