# kmer-context binary classifier training

## Summary

Train mCaller's binary classifiers (NN, RF, NBC, LR) to detect m6A in Oxford Nanopore R9 data by learning from deviations between measured and expected currents over a six-variable k-mer context, using labeled methylated/unmethylated positions confirmed by orthogonal PacBio calls.

## When to use

Use when you have Albacore-basecalled R9 nanopore data (fastq + fast5), a reference fasta, eventalign TSVs, and known motif sites (e.g. E. coli GATC) with labels to train methylation classifiers.

## When NOT to use

- Input reads are from R10.4 flowcells — nanopolish states it does not support R10.4 variant/methylation calling via signal-level analysis
- The target sequence context is dissimilar to the training motifs — mCaller's training biases decrease accuracy at untrained contexts
- The goal is distinguishing between methylation types (e.g. the GATCGVNY motif in S. aureus), which single-molecule methods here fail to separate

## Inputs

- Albacore-basecalled R9 nanopore fastq with matching fast5 files (nanopolish-indexed)
- Reference genome fasta (e.g. E. coli MG1655 K12)
- Labeled positions file (chromosome, position, strand, label) derived from orthogonal PacBio m6A motif calls (e.g. GATC and AACNNNNNNGTGC motifs)
- nanopolish eventalign --scale-events TSV of scaled event-level currents
- Aligned/sorted/indexed BAM from bwa mem -x ont2d

## Outputs

- Trained classifier model saved as a .pkl file (e.g. model_NN_6_m6A.pkl)
- Per-read methylation probability files (*.eventalign.diffs.6)
- Per-position methylation bed file generated by make_bed.py summary script

## How to apply

Build a labeled positions file (space- or tab-separated chromosome, position, strand, label) from orthogonal PacBio m6A calls at motif sites, then index the Albacore-basecalled fastq with nanopolish, align reads to the reference with bwa mem (-x ont2d), and run nanopolish eventalign with --scale-events to produce scaled event-level TSVs. Train by running mCaller.py --train once per classifier using -c NN, RF, NBC, or LR, with the default six-variable (11-mer, 6*2-1) context and default skip_thresh of 0, saving each model as a .pkl file (e.g. model_NN_6_m6A.pkl). Choose training positions from motif sites confirmed with orthogonal PacBio data because the model generalizes poorly to contexts dissimilar to training examples. Apply the trained model to a held-out same-strain dataset's eventalign TSV to compare per-position accuracy across classifiers and select the best performer (in the reference work, the neural network at ~81.3% beat random forest at ~80.8%).

## Examples

```
mCaller.py --train -p positions.txt -r reference.fasta -e sample.eventalign.tsv -f sample.fastq -c NN -b A -d model_NN_6_m6A.pkl
```

## Evaluation signals

- Per-position accuracy on a held-out same-strain E. coli dataset reproduces the reported ranking: NN ~81.3% slightly above RF ~80.8%
- Per-position accuracy falls within the reported 60–98% range across motifs
- Each --train run writes a .pkl model file with the expected naming (e.g. model_NN_6_m6A.pkl)
- Training used the default six-variable (11-mer, 6*2-1) context and skip_thresh 0; changing these should visibly alter model outputs
- Labeled positions file validates as 4-column space/tab-separated (chromosome, position, strand, label) before training

## Limitations

- Training biases can decrease accuracy at contexts with lower similarity to the training examples
- mCaller showed notable failure at one S. aureus motif, indicating incomplete motif coverage
- Published models are specific to R9.4/R9.5 data basecalled with Albacore and trained on E. coli
- Both single-molecule methods can fail to distinguish between types of methylation (GATCGVNY motif in S. aureus)
