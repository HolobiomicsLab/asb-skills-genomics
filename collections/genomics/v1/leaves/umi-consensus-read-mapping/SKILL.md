# umi-consensus-read-mapping

## Summary

Maps UMI-guided error-corrected consensus reads from Nanopore single-cell data to a reference genome and assigns them to annotated transcript isoforms, producing gene-, isoform-, and junction-level UMI count matrices with Sicelore.

## When to use

Use when raw Nanopore long reads from a 10x Genomics droplet scRNA-seq library must be converted into per-cell gene/isoform UMI count matrices via consensus sequences and strict Gencode isoform assignment.

## When NOT to use

- Input is raw short-read (Illumina) scRNA-seq data rather than Nanopore/PacBio long reads — Sicelore's long-read consensus and isoform assignment do not apply.
- The goal is novel isoform discovery from unannotated splice junctions rather than assignment of UMIs to known Gencode transcript isoforms (METHOD=STRICT discards novel structures).
- Only cell barcode/UMI-tagged long reads exist without UMI consensus FASTQs from ComputeConsensus, i.e. Step 4 option a (IsoformMatrixReads) would be used instead of the molecules-based path.

## Inputs

- Per-chromosome molecule consensus FASTQs generated by the Sicelore ComputeConsensus step
- Reference genome (e.g. hg38)
- Gencode annotation GTF (e.g. gencode.v38.primary_assembly.annotation.gtf) converted to refFlat with gtfToGenePred
- ValidBarcodes.csv whitelist of cell barcodes
- Sicelore-2.1.jar, minimap2, samtools, Java >= 13

## Outputs

- molecules.bam (minimap2 spliced alignment of consensus reads, sorted and indexed)
- molecules.GE.tags.bam (BAM with GE gene-name, BC, U8 and RN tags)
- _genematrix.txt (gene-level UMI counts per cell)
- _isomatrix.txt (isoform-level UMI counts per cell)
- _juncmatrix.txt (junction-level counts)
- _molinfos.txt (molecule information)

## How to apply

Concatenate per-chromosome molecule consensus FASTQs from the ComputeConsensus step and deduplicate multi-copy-gene molecules with Sicelore-2.1.jar DeduplicateMolecule. Align consensus reads to the reference genome (e.g. hg38) with minimap2 in spliced forward-strand mode ('minimap2 -ax splice -uf --sam-hit-only -t 20') and sort/index the resulting molecules.bam with samtools. Annotate SAM records with gene names via Sicelore-2.1.jar AddGeneNameTag (TAG=GE, REFFLAT from a Gencode GTF converted with gtfToGenePred, ALLOW_MULTI_GENE_READS=true, USE_STRAND_INFO=true), then transfer BC (cell barcode), U8 (UMI) and RN (read number) tags into the BAM with AddBamMoleculeTags. Finally run Sicelore-2.1.jar IsoformMatrix on molecules.GE.tags.bam with GENETAG=GE, UMITAG=U8, CELLTAG=BC, DELTA=2, MAXCLIP=150, METHOD=STRICT, AMBIGUOUS_ASSIGN=false, MAPQV0=false, requiring full exonic-structure matches to annotated transcripts to assign isoforms.

## Examples

```
java -jar Sicelore-2.1.jar IsoformMatrix INPUT=molecules.GE.tags.bam GENETAG=GE UMITAG=U8 CELLTAG=BC REFFLAT=refFlat CSV=ValidBarcodes.csv DELTA=2 MAXCLIP=150 METHOD=STRICT AMBIGUOUS_ASSIGN=false MAPQV0=false
```

## Evaluation signals

- Fraction of UMIs assigned to a known Gencode transcript isoform via full exonic-structure matching should match the reported ~63.6%.
- Number of fully supported transcripts should match the reported ~33,002.
- Per-cell median gene-UMIs should be ~6047 and median isoform-UMIs ~3795.
- Confirm presence and structure of the emitted _genematrix.txt, _isomatrix.txt, _juncmatrix.txt and _molinfos.txt files in the output directory.
- Verify the BAM carries GE, BC, U8 and RN tags after AddGeneNameTag and AddBamMoleculeTags.

## Limitations

- Isoform assignment uses METHOD=STRICT with AMBIGUOUS_ASSIGN=false, so reads with ambiguous isoforms or novel exon structures are not assigned; DELTA=2 allows only a 2-base margin of added or lacking sequences at exon boundaries.
- SAM records with extensive clipping (MAXCLIP > 150 nt) are discarded as potential chimeric cDNA, losing reads.
- Requiring full exonic-structure matching caps the assignable fraction at ~63.6% of UMIs, so a large share of molecules remain isoform-unassigned.
