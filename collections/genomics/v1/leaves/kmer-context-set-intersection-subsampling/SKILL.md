# kmer-context-set-intersection-subsampling

## Summary

Balances CHH methylation training samples across 9-mer sequence contexts for DeepPlant by intersecting positive/negative 9-mer sets, enforcing a ≥50-positive-sample coverage threshold, and subsampling to per-9-mer class parity. This counters the scarcity of methylation-positive CHH samples that otherwise biases the R10.4 nanopore model.

## When to use

Use when constructing a DeepPlant CHH training set from extract_hc_sites npz feature files and you need per-9-mer context parity between methylation-positive and negative samples before model training.

## When NOT to use

- Input is raw pod5/BAM data with no extract_hc_sites output yet — run extract_hc_sites (pod5_dir bam_path reference_path ref_type write_dir pos neg kmer_size num_workers) first to produce the pos/neg npz files.
- The context is CpG or CHG methylation, where methylation-positive samples are abundant rather than scarce high-methylation CHH contexts.
- Samples were generated by in vitro enzyme-catalyzed methylation or PCR with modified base substitutions — the paper reports these are ineffective or alter base contexts for CHH positives.

## Inputs

- Positive CHH npz feature file from DeepPlant extract_hc_sites (kmer_size=13; uint8 site-info array plus data array; tab-delimited site info strings)
- Negative CHH npz feature file from DeepPlant extract_hc_sites (same npz layout)
- k_max cap parameter for per-9-mer sample counts

## Outputs

- balanced_chh_training_samples.npz — balanced CHH dataset in the same npz layout (uint8 site-info array plus data array) with 1:1 positive:negative ratio overall and per 9-mer context

## How to apply

Load the positive and negative CHH npz feature files produced by DeepPlant's extract_hc_sites (kmer_size 13, CHH motif) and parse each sample's tab-delimited site info string to obtain the 9-mer context centered on the CHH motif. Compute the intersection of the positive and negative 9-mer sets and keep only samples whose 9-mer falls in this intersection, applying the coverage criterion that a 9-mer must appear in at least 50 positive CHH training samples and have at least an equal number of negatives. Cap per-9-mer counts at k_max in both classes so no single motif context dominates, then randomly subsample each class so every retained 9-mer has equal positive and negative counts. Save the result as balanced_chh_training_samples.npz in the same npz layout (uint8 site-info array plus data array). Rationale: CHH methylation depends on RdDM so positives are scarce, and unbalanced motif contexts drive overfitting to specific sequence patterns.

## Related tools

- **DeepPlant** (Provides extract_hc_sites, which produces the positive/negative CHH npz feature files (kmer_size 13) whose tab-delimited site info strings encode the 9-mer contexts that this balancing skill operates on) — github.com/xiaochuanle/DeepPlant
- **cnpy** (C++ library used in the DeepPlant framework for reading/writing the .npy/.npz files that carry the site-info and data arrays before and after balancing) — https://github.com/rogersce/cnpy

## Examples

```
extract_hc_sites pod5_dir bam_path reference_path ref_type write_dir pos neg 13 num_workers  # then intersect pos/neg 9-mer sets, cap at k_max, subsample to parity, save balanced_chh_training_samples.npz
```

## Evaluation signals

- Output balanced_chh_training_samples.npz shows an overall 1:1 positive:negative sample ratio
- Every retained 9-mer context contributes equal numbers of positive and negative samples (per-9-mer class parity check)
- No retained 9-mer has fewer than 50 positive CHH training samples, and each retained 9-mer has at least an equal number of negative samples
- No retained 9-mer context exceeds the k_max cap in either class
- Output file preserves the npz layout (uint8 site-info array plus data array) of the extract_hc_sites inputs

## Limitations

- Scarcity of high-methylation CHH samples, although partially mitigated by this balancing across the ~97.2% of 9-mer CHH contexts covered, continues to pose challenges for model training and generalization
- Reliance on species with naturally abundant CHH methylation (S. miltiorrhiza, S. tuberosum, R. communis) may not capture the full diversity of methylation patterns across all plant species
- Unbalanced or poorly filtered 9-mer contexts risk overfitting to specific sequence patterns, requiring careful model optimization and validation
