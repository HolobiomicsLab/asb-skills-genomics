# random-forest-pixel-classification

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Random forest-based machine learning pixel classification (trained in Ilastik) that defines intracellular compartments — nucleus, membrane, and cytoplasm — from multiplexed immunofluorescence tissue images, providing the input to MIRIAM's membrane-based cell segmentation.

## When to use

Use when segmenting cells from multiplexed imaging data (e.g., multiplexed immunofluorescence colorectal adenoma images or MIBI breast carcinoma images) and you need pixel-level classification of cellular compartments to seed membrane-based resegmentation.

## When NOT to use

- When nuclei-only inputs are available and no membrane markers were imaged — the article shows omitting membrane markers plus DAPI markedly decreased similarity to annotated cell borders.
- When a deep-learning segmentation tool such as Mesmer is preferred and training-on-annotation infrastructure is unavailable; note MIRIAM outperformed Mesmer on the manually annotated colorectal adenoma data but Mesmer requires no per-project classifier training.
- When images are too large for the provided example workflow — the README notes image stacks are excluded from example data and must be regenerated by the user.

## Inputs

- Multiplexed immunofluorescence image stacks (e.g., colorectal adenoma TMA images as 512x512 sub-images)
- Manually annotated cell-border/compartiment labels for training the Ilastik pixel classifier
- Marker channel set (e.g., membrane markers such as NaKATPase, plus DAPI and other markers)

## Outputs

- Pixel-classification probability maps defining nucleus, membrane, and cytoplasm compartments (input to MIRIAM segmentation)
- Per-cell segmentations and per-cell marker quantification over entire cell and nucleus, membrane, cytoplasm compartments
- Image-level Dice (DSC) and Jaccard (JSC) similarity scores against manual annotations (e.g., ablation_similarity_scores.csv)

## How to apply

Load the multiplexed image stacks (e.g., colorectal adenoma TMA cores partitioned into 512x512 sub-images; 240 sub-images across three annotated TMA cores) into Ilastik alongside manual annotations of cell borders and compartments. Train the random-forest pixel classifier using the full marker set, since the article reports that using all markers to define intracellular structures resulted in more complete membranes, whereas dropping membrane markers plus DAPI or training on only NaKATPase+DAPI degraded similarity to manual annotations. Use the classifier's probability/object output as the input to the MIRIAM segmentation step, which identifies and separates cells with internal membranes; the pipeline itself is implemented in Matlab (with a Python alternative) and requires downloading Ilastik. Benchmark the resulting segmentations against manually annotated cell borders using image-level DSC and JSC, expecting a baseline near DSC 0.65 ± 0.08 and JSC 0.48 ± 0.08. The README states the pipeline is Matlab code that requires Ilastik, with example data and a tutorial provided.

## Evaluation signals

- Image-level Dice similarity coefficient against manually annotated cell borders should reach approximately DSC 0.65 ± 0.08 when the full marker set is used.
- Image-level Jaccard similarity coefficient should reach approximately JSC 0.48 ± 0.08 for the full-model baseline.
- Ablation check: dropping any single marker should minimally change DSC/JSC, whereas dropping membrane markers plus DAPI (or using only NaKATPase+DAPI) should visibly decrease similarity to manual annotations.
- MIRIAM segmentation (seeded by this classifier) should outperform Mesmer (DSC 0.59 ± 0.10) and Voronoi (DSC 0.32 ± 0.11) on the same annotated colorectal adenoma sub-images.
- Matlab and Python implementations of the downstream pipeline should yield largely similar segmentation results (Supplemental Figure 6).

## Limitations

- Omitting membrane markers and DAPI from pixel-classifier training substantially decreases similarity to manually annotated cell borders; NaKATPase+DAPI-only training is likewise degraded.
- Quantitative similarity scores for some comparisons are only referenced via figure pointers (Fig. 2H, I) rather than reported in text; no version numbers are stated for the Matlab or Python implementations.
- Manually annotated ground-truth data and image stacks are not fully packaged with the repository — example data omits image stacks, which the user must regenerate/download separately.
