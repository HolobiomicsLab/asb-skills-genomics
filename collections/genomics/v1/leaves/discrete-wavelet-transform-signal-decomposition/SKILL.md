# discrete-wavelet-transform-signal-decomposition

## Summary

Encodes each PSSM evolutionary profile as 20 discrete signals and compresses them via 4-scale Discrete Wavelet Transformation into a fixed 1040-dimension PSSM-DWT descriptor, contributing to iDBP-DEP's 3240-dimension multi-view feature vector for DNA-binding protein detection.

## When to use

Use when converting variable-length N x 20 PSSM matrices into fixed-length feature vectors for sequence-level protein classification, requiring compression of evolutionary signal noise via DWT.

## When NOT to use

- Input is already a fixed-length feature table (e.g. precomputed DDE, PSSM-DBT or NMBAC .mat files) rather than raw PSSM profiles
- The analysis targets residue-level prediction rather than whole-protein (sequence-level) DNA-binding protein classification
- Variable-length sequences can be handled directly without compression and preserving full N x 20 resolution is preferred over the fixed 1040-dimension summary

## Inputs

- N x 20 PSSM profile matrix per protein sequence (generated by PSI-BLAST, 3 iterations, e-value 0.001, against the nr database)
- Protein sequence set (e.g. PDB1075, PDB594, PDB186 FASTA sequences with accompanying PSSM text files such as those in PDB1075_seqs_PSSM)

## Outputs

- 1040-dimension PSSM-DWT feature vector per protein
- Serialized MATLAB .mat workspace file (e.g. PSSM_DWT.mat / PSSM_DWT_594_workspace.mat) containing the feature matrix, ready to be concatenated with DDE, PSSM-DBT and NMBAC descriptors into a 3240-dimension vector

## How to apply

Generate the PSSM profile with PSI-BLAST against the nr database (3 iterations, e-value 0.001), then treat each N x 20 PSSM matrix as 20 discrete signals of length N. Apply Discrete Wavelet Transformation, decomposing approximation coefficients with low-pass/high-pass filters and down-sampling, iterated 4 times ('we implemented the decomposition for 4 times'). At each of the 4 scales compute the maximum, minimum, mean and standard deviation of both approximation and detailed coefficients (32 features per signal), and additionally extract the top five discrete cosine transform coefficients from the approximation coefficients to add 20 more features per signal (52 total per signal). Concatenate across all 20 amino-acid signals to yield the 20 x 52 = 1040-dimension PSSM-DWT vector per protein, and serialize as a MATLAB .mat workspace file (e.g. PSSM_DWT_186.mat) for downstream combination with DDE, PSSM-DBT and NMBAC descriptors into the 3240-dimension feature vector.

## Related tools

- **PSI-BLAST** (Generates the PSSM evolutionary profiles that are input to the DWT encoding, by searching each target protein against the nr database)
- **MATLAB DWT scripts (getDWT.m, EstraggoConDWT.m, ExDWT_demo.txt)** (Implement the 4-scale discrete wavelet decomposition and coefficient statistics that produce the PSSM-DWT .mat feature files) — https://githup.com/Zll-codeside/iDBP-DEP

## Evaluation signals

- Verify the serialized .mat feature matrix contains exactly 1040 feature dimensions per protein, matching the paper's stated PSSM-DWT dimensionality (20 signals x 52 features)
- Check each amino-acid signal contributes exactly 52 features: 32 from max/min/mean/std of approximation and detailed coefficients at 4 scales, plus 20 from top five DCT coefficients
- Confirm downstream concatenation yields the full 3240-dimension vector: 1040 (PSSM-DWT) + 200 (NMBAC) + DDE + PSSM-DBT dimensions
- Compare generated PSSM_DWT .mat files against the repository's shipped feature data (e.g. ~/Data/PDB1075/Feature Data/PSSM_DWT.mat) for consistency

## Limitations

- Requires precomputed PSI-BLAST PSSM profiles, whose quality depends on nr database version and search parameters not fully pinned down (no PSI-BLAST version stated)
- The fixed 1040-dimension descriptor discards sequence-length information via down-sampled wavelet compression; feature selection (SVM-RFE+CBR) is applied afterwards to remove noisy and redundant features
- Implementation is MATLAB-specific (getDWT.m, .mat serialization), limiting direct reuse in Python pipelines without conversion
