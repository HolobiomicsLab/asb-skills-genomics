# ONT basecaller-guided loss implementation

## Summary

Implements NanoSimFormer's multi-objective training loss, combining MSE terms on per-base mean signal level and noise standard deviation (from resquiggle-derived dwell times) with a CTC negative log-likelihood loss computed through a frozen pre-trained ONT Dorado basecaller.

## When to use

Use when training a nanopore signal simulator on POD5/BAM-derived training chunks and you need a differentiable basecaller-guided CTC objective alongside signal-level MSE losses.

## When NOT to use

- Input is simulated signals already generated by a trained simulator — this skill is the training objective, not the simulate CLI path
- You only need basecalling of simulated reads into FASTQ/BAM — use the --basecall/--emit-bam options with Dorado instead
- No resquiggle-derived dwell times (dwells.npy) are available, since the MSE targets require per-base dwell assignments

## Inputs

- Training chunk files: signal.npy, sequence.npy, sequence_length.npy, dwells.npy
- Aligned BAM + POD5 files used by create_dataset
- Pre-trained ONT basecalling model (Dorado v5 super-accuracy, dna_r1041 or rna004 preset) loaded via bonito

## Outputs

- Trained Transformer signal simulator checkpoint written to weights/ per epoch
- TensorBoard training loss curves in the output log/ directory
- Combined CTC + MSE loss values during training

## How to apply

Load the training dataset (signal.npy, sequence.npy, sequence_length.npy, dwells.npy) with the NanoSimFormer loader, verifying per-base dwell times sum to signal_chunk_len (5000 samples for dna_r1041, 4000 for rna004). Implement the BaseCaller subclass (ONTOBasecaller default) whose load_model loads the frozen pretrained ONT model via bonito and puts it in eval mode so weights are not updated. Compute the CTC loss with torch.nn.functional.ctc_loss on log-softmax logits permuted to (time, batch, classes), encoding targets as A=1, C=2, G=3, T/U=4, pad=0 with unpadded lengths from sequence_length.npy. Add MSE terms on per-base mean signal and noise standard deviation against dwell assignments in dwells.npy, then train with DDP (e.g. --ngpus 2, batch-size 64, lr 0.0002, epochs 5, seed 42).

## Examples

```
python -m nano_signal_simulator train --ngpus 2 --batch-size 64 --lr 0.0002 --epochs 5 --seed 42
```

## Evaluation signals

- Per-base dwell times summed from dwells.npy equal signal_chunk_len (5000 for dna_r1041, 4000 for rna004)
- Frozen basecaller weights remain unchanged (model in eval mode; no gradients) after a training epoch
- CTC loss is finite and decreases across epochs, computed on log-softmax logits of shape (time, batch, classes) with target encoding A=1, C=2, G=3, T/U=4, pad=0
- Per-epoch checkpoints appear in weights/ and tensorboard --logdir on the log/ directory shows declining combined loss
- Final simulator reaches median basecalling accuracy exceeding 99% with Q-scores above 22.8 on R10.4.1 DNA / direct RNA evaluation

## Limitations

- Requires the exact ONT chemistry presets (dna_r1041, rna004); adapting to new chemistry needs the documented extension guide and new checkpoints
- pip/conda installs require manually downloading model checkpoints from Zenodo (10.5281/zenodo.20364515); the Docker image bundles them
- Needs NVIDIA GPU with CUDA compute capability >= 8.x and driver >= 525; flash-attn installation adds an extra build step for pip users
