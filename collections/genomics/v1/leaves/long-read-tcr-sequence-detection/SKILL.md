# long-read-tcr-sequence-detection

## Summary

Detects T-cell receptor (TCR) sequences per single cell by running the nanoranger long-read pipeline (5p10X_XCR mode) on ONT-sequenced amplicons derived from 5′-anchored 10x Genomics scRNA-seq cDNA libraries, yielding per-cell TCR counts comparable to Illumina-based TCR sequencing.

## When to use

Use when you have ONT (or PacBio) FASTQs from targeted amplification of a 10x Genomics V(DJ) cDNA library and need per-cell-barcode TCR calls, e.g. tumor-infiltrating T cell TCR profiling with nanoranger.

## When NOT to use

- Input is short-read Illumina data only — the skill is for long-read (ONT/PacBio) reads from intermediate single-cell cDNA libraries
- Input is bulk TCR/BCR repertoire data without 10x cell barcodes and UMIs — per-cell assignment is not possible
- Target loci are not near the 5′ end or transcripts exceed ~4 kB — outside nanoranger's defined optimal target space

## Inputs

- ONT (or PacBio) FASTQ from targeted amplification of a 10x Genomics V(DJ)/TCR cDNA library
- Sample FASTQ provided with the nanoranger repository (melanoma T cell TCR library)
- TCR target reference for long-read alignment

## Outputs

- Per-cell TCR calls keyed by 10x cell barcode
- Aggregated cell counts (e.g. tcr_cell_counts.csv) of cells with a detectable TCR

## How to apply

Obtain the sample FASTQ generated by targeted amplification of the 10x Genomics whole-transcriptome cDNA library (e.g. the melanoma tumor-infiltrating T cell TCR library shipped with the nanoranger repository) and sequenced on an Oxford Nanopore Technologies device. Execute the nanoranger workflow in 5p10X_XCR mode so long reads are aligned to the TCR target and TCR sequences are called per 10x cell barcode. Aggregate the per-cell TCR calls and count cells with a detected TCR sequence, writing the result (e.g. to tcr_cell_counts.csv). Verify against the paper reference: nanoranger detected TCRs in 5653 ONT cells versus 5767 TCR-positive cells by Illumina sequencing, with reported ONT–Illumina concordance of r=0.8 and r=0.9. For downstream processing, pass nanoranger amplicon output to nanoranger.R, which uses starcode to collapse sequencing-error UMIs within a Levenshtein distance of 3, since 10x UMIs lack a correction whitelist.

## Evaluation signals

- Cell count of TCR-positive cells matches the paper reference of 5653 ONT cells (Illumina comparator: 5767 cells)
- ONT–Illumina TCR detection concordance falls at the reported r=0.8 to r=0.9 range
- Every TCR call is assigned to a whitelisted 10x Genomics cell barcode from the input library
- Downstream UMI collapse in nanoranger.R groups sequences within Levenshtein distance 3, as specified

## Limitations

- nanoranger's optimal targets are loci close to the 5′ end of highly expressed genes with transcript lengths shorter than 4 kB; targets outside this regime underperform
- The genotyping ceiling is set by low, incomplete transcript representation and cannot be overcome by amplicon optimization or deeper sequencing
- ONT sequencing error must be handled by pipeline-side correction (whitelisted barcodes, starcode UMI collapsing at distance 3)
