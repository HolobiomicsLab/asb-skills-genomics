# gwas-summary-statistics-format-conversion

## Summary

Converts simulated GWAS summary statistics (IV–exposure and IV–outcome estimates) generated by simmrd's generate_summary() into an mr_input object for the MendelianRandomization R package, enabling fitting of standard summary-data MR estimators such as IVW and MR-Egger on simulated replicates.

## When to use

Use when you hold SNP-level vectors bx, bxse, by, byse (e.g. from simmrd's generate_summary() output) and need to run established summary-data MR estimators on them via the MendelianRandomization package.

## When NOT to use

- You have individual-level genotype and phenotype data from simmrd::generate_individual() and need methods that require individual-level data rather than summary statistics
- You need an MR method not implemented in the MendelianRandomization package (e.g. dIVW, MR-Robust, MR-RAPS mentioned in the article) — run it directly instead of converting to mr_input
- The bx/by vectors come from different SNPs or are not aligned between exposure and outcome GWAS

## Inputs

- simmrd generate_summary() named list with elements bx (m x p matrix), bxse, by (m x 1 vector), byse, theta, LDMatrix
- Alternatively, any GWAS summary-data vectors of SNP–exposure associations with standard errors and SNP–outcome associations with standard errors
- True causal effects theta from simmrd for comparison context

## Outputs

- MendelianRandomization mr_input object built from bx/bxse/by/byse
- Fitted MR estimator results (e.g. IVW or MR-Egger causal effect estimates)
- Structured CSV record (e.g. mr_estimates.csv) with estimator name and causal effect estimate(s)

## How to apply

Take the named-list output of simmrd::generate_summary() — the m x p matrix bx of IV–exposure associations with standard errors bxse, the m x 1 vector by of IV–outcome associations with standard errors byse, and theta for the true causal effects — and build a MendelianRandomization input object (mr_input) from these vectors. For multivariable simulations (number_of_exposures > 1), pass all p exposure columns of bx with their matching bxse columns. Fit at least one summary-data estimator on the object, e.g. mr_ivw() or mr_egger(), and extract the causal effect estimate(s). Compare the estimates against simmrd's returned theta (true_causal_effects) to contextualize bias or agreement. Write estimator names and causal estimates to a structured record such as mr_estimates.csv. Rationale: the article explicitly demonstrates (Figure 4) that simmrd-generated summary data for three exposures integrate with the MendelianRandomization package, making this the validated bridge between simmrd simulation and off-the-shelf MR estimation.

## Examples

```
library(simmrd); library(MendelianRandomization); data <- generate_summary(set_params()); obj <- mr_input(bx = data$bx, bxse = data$bxse, by = data$by, byse = data$byse); fit <- mr_ivw(obj)
```

## Evaluation signals

- The output CSV (e.g. mr_estimates.csv) exists and parses as valid CSV
- Each estimator run yields a finite numeric causal effect estimate
- Estimates are comparable to simmrd's true causal effects (theta), e.g. IVW should be near theta under valid-IV default settings (true_causal_effects default 0.3)
- The mr_input object dimensions match the simulation: m IVs by p exposures, matching bx and by row counts
- Estimator results change as expected when parameters like number_of_UHP_causal_SNPs or number_of_CHP_causal_SNPs introduce pleiotropy, confirming the replicate integrates correctly

## Limitations

- generate_summary() and generate_individual() produce data for a single simulation replicate; multi-replicate Monte Carlo runs require the CLI or repeated calls
- simmrd-simulated IVs include invalid instruments ('UHP' or 'CHP' per IVtype), so estimators assuming all-valid IVs (e.g. plain IVW) may be biased under pleiotropic presets
- The article notes no standard simulation framework exists for MR, so performance comparisons across independently run simulations may be unreliable
