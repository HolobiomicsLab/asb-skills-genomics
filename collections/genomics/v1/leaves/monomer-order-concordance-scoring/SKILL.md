# monomer-order-concordance-scoring

## Summary

Scores how well a single-breakend contig sequence matches the high-order repeat (HOR) structure of centromeres by decomposing it into monomers with StringDecomposer and summing monomer-pair concordance against curated HOR definitions from HORmon.

## When to use

Use when assessing whether contigs from 'High Repeat single breakend SVs' (mostly RepeatMasker 'Satellite/centr') match canonical, chromosome-specific centromeric HORs or non-canonical HOR orders.

## When NOT to use

- The contig is not from a 'High Repeat single breakend SV' or lacks a Satellite/centromere RepeatMasker annotation — the HOR decomposition and scoring assume centromeric repeat content.
- A suitable HORmon monomer FASTA for the chromosome of interest is not available, since scoring depends on the curated cen*_monomers.fa and cen*_hors.tsv definitions.

## Inputs

- Contig sequences of single breakend SVs from the nanomonsv single breakend result file (Contig column), classified as 'High Repeat single breakend SVs' and mostly annotated 'Satellite/centr' by RepeatMasker
- HORmon final monomer FASTA files (cen*_monomers.fa under the monomersFinal directory) per chromosome
- HORmon curated HOR definitions (cen*_hors.tsv from the HORmonHORs directory)

## Outputs

- final_decomposition.tsv per chromosome monomer file from StringDecomposer
- hor_match_scores.csv with columns for contig ID, chromosome, and HOR match score (0-1)

## How to apply

Extract contigs of single breakend SVs classified as 'High Repeat single breakend SVs' from the nanomonsv single breakend result file (Contig column), which are mostly annotated 'Satellite/centr' by RepeatMasker. Run StringDecomposer version 1.1.2 on each contig against the final monomer FASTA generated by HORmon (cen*_monomers.fa under the monomersFinal directory) for the relevant chromosome, producing a final_decomposition.tsv. Read that file line by line and, for each adjacent monomer pair whose pre-/post-relationship is consistent with the curated HOR definitions (cen*_hors.tsv from the HORmonHORs directory), add (<end-pos> - <start-pos>) * <identity> / 100 to a running sum. Divide the summed concordance by the contig length to obtain the HOR match score; write per-contig scores to hor_match_scores.csv with columns for contig ID, chromosome, and HOR match score.

## Related tools

- **nanomonsv** (Source of the single breakend SV result file from which 'High Repeat single breakend SVs' contigs (Contig column) are extracted for scoring) — https://github.com/friend1ws/nanomonsv

## Examples

```
sd -d cenX_monomers.fa contig.fa; then parse final_decomposition.tsv: if pre/post pair in cenX_hors.tsv: score += (end_pos - start_pos) * identity / 100
```

## Evaluation signals

- Each HOR match score must fall within the valid range 0-1, since the summed (end-pos - start-pos) * identity / 100 cannot exceed the contig length.
- Scores should reproduce the paper's qualitative result: most contigs match canonical, chromosome-specific HORs, with a minority of non-canonical HORs.
- Known non-canonical case to check against: the 17-mer ABCDEFGHIJKLHIJKL HOR on chromosome X.
- final_decomposition.tsv must exist for every contig / chromosome monomer file combination processed by StringDecomposer.
- hor_match_scores.csv must contain contig ID, chromosome, and HOR match score columns and cover all extracted contigs.

## Limitations

- nanomonsv's single breakend module cannot detect SVs where both breakpoints are located in poorly characterized, highly repetitive regions — contigs must have one resolvable breakpoint outside the repeat.
- The scoring workflow interprets complex SV structure largely manually; the article notes such interpretation is not fully automated.
- Reference-genome-based frameworks like nanomonsv may not appropriately capture long repeat expansion events because the reference is unreliable in regions susceptible to these.

## Evidence

- [abstract] Single breakend SV module enables the detection of complex SVs that can only be identified by long-reads, such as SVs involving highly-repetitive centromeric sequences: "Single breakend SV module enables the detection of complex SVs that can only be identified by long-reads, such as SVs involving highly-repetitive centromeric sequences"
- [intro] Single breakend SV module of nanomonsv can identify single breakend SVs where only one breakpoint is identified: "Single breakend SV module of nanomonsv can identify single breakend SVs where only one breakpoint is identified"
- [discussion] it cannot detect SVs where both of the breakpoints are located in areas where reference genomes are not well-characterized, such as highly repetitive regions: "it cannot detect SVs where both of the breakpoints are located in areas where reference genomes are not well-characterized, such as highly repetitive regions"
- [discussion] the interpretation of the detailed structure and properties of complex SVs is not fully automated at present, and much of the work is done manually: "the interpretation of the detailed structure and properties of complex SVs is not fully automated at present, and much of the work is done manually, which remains a challenge for processing many"
