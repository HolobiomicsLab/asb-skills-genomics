# transcript-annotation-classification

## Summary

Annotate and classify PacBio Iso-seq full-length transcripts against a reference genome and Ensembl GTF using TAGET's TransAnnot, producing per-read transcript classifications (FSM/ISM/NIC/NNC/GENIC/INTERGENIC/FUSION) and splice-junction records. This enables accurate novel splice-site and novel isoform discovery beyond what standard long-read aligners report.

## When to use

Use when you have a PacBio Iso-seq full-length transcript FASTA and need to classify each read against a reference annotation (e.g., hg38) to detect known vs novel splice junctions, isoforms, or gene fusions.

## When NOT to use

- The goal is transcript reconstruction/quantification from short-read RNA-seq rather than classification of full-length long reads — reconstruction tools like StringTie2 or FLAIR are designed for that
- No reference genome or annotation GTF is available for the organism, since classification depends on comparing reads to hg38-style GTF annotation
- Input is short-read RNA-seq FASTQ rather than Iso-seq full-length transcript FASTA

## Inputs

- Full-length transcript FASTA from PacBio Iso-seq (CCS reads)
- Reference genome FASTA (e.g., hg38.fa)
- Reference annotation GTF (e.g., hg38.ensembl.gtf)
- Annotation pickle database generated by gtf_db_make.py
- HISAT2 genome index built with hisat2-build (optional aligner)

## Outputs

- {sample_id}.annot.stat — per-read classification, gene/transcript assignment, and end-difference metrics
- {sample_id}.annot.junction — splice junction records
- {sample_id}.annot.bed — annotated genes in BED format
- {sample_id}.annot.multiAnno — multi-annotation transcripts
- {sample_id}.annot.cluster.reads/transcript/gene — read, transcript, and gene clusters

## How to apply

First build the annotation pickle database from the Ensembl GTF (e.g., hg38.ensembl.gtf) with gtf_db_make.py, and index the reference genome (hg38.fa) for HISAT2 via hisat2-build and/or minimap2. Then run TransAnnot.py with the full-length transcript FASTA, genome FASTA, GTF annotation, and aligner settings configured in TransAnnot.Config (READ_LENGTH 100, READ_OVERLAP 80, MIN_READ_LENGTH 30), enabling --use_minimap2 and --use_hisat2 as needed. TransAnnot aligns reads independently rather than reconstructing transcripts, which yields higher sensitivity than reconstruction-based tools (FLAIR, StringTie2, IsoQuant), and classifies each read's transcript structure into categories such as FSM, ISM, NIC, NNC, GENIC, INTERGENIC, FUSION, and UNKNOWN. Inspect {sample_id}.annot.stat for per-read classification, gene/transcript assignment, and 5'/3' end differences to annotation, and {sample_id}.annot.junction for detected splice junctions. Novel-junction calls from TAGET are significantly more precise than those of current alignment tools, for which over 40% of predicted novel junctions are non-canonical (often false positives).

## Related tools

- **TAGET** (Core toolkit; TransAnnot.py performs transcript alignment, junction prediction, and read classification into FSM/ISM/NIC/NNC etc.) — https://github.com/XiDsLab/TAGET
- **HISAT2** (Short-read alignment engine used within TransAnnot (read length 100, overlap 80, min read length 30); index built with hisat2-build)
- **MINIMAP2** (Long-read aligner used within TransAnnot to map full-length Iso-seq transcripts to the genome)
- **samtools** (SAM/BAM processing dependency for the TransAnnot pipeline)

## Examples

```
python TransAnnot.py -f transcripts.fasta -g hg38.fa -o outdir -a hg38.ensembl.gtf -p 8 --use_minimap2 1 --use_hisat2 hg38_index
```

## Evaluation signals

- {sample_id}.annot.stat contains one row per read with a Classification value among FSM, ISM, NIC, NNC, GENIC, INTERGENIC, FUSION, UNKNOWN
- {sample_id}.annot.junction exists and contains per-junction records usable as the input for sensitivity/precision benchmarking
- In annotation-deletion simulations (5–50% of genes removed), TAGET junction-recovery sensitivity should exceed that of StringTie2 and FLAIR (Supplementary Fig. 5 pattern)
- The fraction of non-canonical novel junctions should be markedly lower than the >40% reported for current alignment tools
- Demo pipeline (data.7z, demo.7z, script.7z) completes in under ~1 hour on 8 cores, confirming the configuration is correct

## Limitations

- Over 40% of novel junctions predicted by current alignment tools are non-canonical, indicating many novel-junction calls are false positives if TAGET's classification step is skipped
- Different isoforms can share junctions, causing ambiguity for downstream isoform quantification if annotation/classification is inaccurate
- Classification requires both hg38.fa and Ensembl GTF inputs plus indexed references; mis-specified HISAT2/minimap2 paths or index files in TransAnnot.Config will break the run
