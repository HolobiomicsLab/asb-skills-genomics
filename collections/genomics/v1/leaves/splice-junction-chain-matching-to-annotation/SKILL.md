# splice-junction-chain-matching-to-annotation

## Summary

Classifies full-length nanopore transcripts detected in dRNA or cDNA runs against a reference GTF by matching their splice junction chains, labeling each transcript as a known isoform, ISM, NIC, or NNC. In the Dogme pipeline this is the step that turns LR-Kallisto-detected isoforms into a per-replicate isoform-class table.

## When to use

Use when minimap2-spliced nanopore BAMs (direct RNA or cDNA) contain full-length reads whose isoforms must be labeled known/ISM/NIC/NNC against a reference transcript annotation, e.g., testing isoform-class reproducibility across C2C12 dRNA replicates.

## When NOT to use

- The goal is modified-base calling or filtering (Dorado/modkit on RNA or DNA POD5), not isoform structure annotation — use the modkit workflow instead.
- Input is still unmapped POD5/FASTQ and only basecalling or remapping is needed — use the basecall or remap entry points rather than annotateRNA.
- Reads are short reads or otherwise lack full-length splice junction chains, so ISM/NIC/NNC junction-chain rules cannot be meaningfully applied.

## Inputs

- Mapped (spliced-aligned) BAM files per replicate from Dogme/minimap2 (dRNA or cDNA)
- Reference genome and transcript annotation GTF
- Junction BED derived from the GTF (auto-generated by gtf_to_junction_bed.py)
- LR-Kallisto transcript quantification output identifying detected full-length isoforms per replicate

## Outputs

- Annotated BAM files with transcript information attached to reads
- TALON-compatible isoform classification outputs (known, ISM, NIC, NNC)
- transcript_class_counts.csv with per-class transcript counts per replicate
- QC summary CSVs per genome (expanded QC CSVs from annotateRNA.py)

## How to apply

Start from BAMs that were spliced-mapped by Dogme/minimap2 — Dogme first converts the reference GTF to a junction BED (`scripts/gtf_to_junction_bed.py`) and maps with `--splice-max 500000` so long introns are represented. Run the `annotateRNA` entry point or `scripts/annotateRNA.py` on the mapped BAMs together with the reference genome/GTF; this annotates reads with transcript information and emits TALON-compatible outputs. Apply the splice-site matching rules: exact splice-junction-chain agreement with an annotated isoform = known; partial junction-chain match = ISM; novel combinations of known splice sites = NIC; unannotated splice sites = NNC. Use the `-CDNA` flag for cDNA-specific behavior. Repeat per replicate (here, the three mouse C2C12 myoblast dRNA MinION replicates quantified with LR-Kallisto), then aggregate transcript counts per class (known, ISM, NIC, NNC) per replicate into transcript_class_counts.csv.


## Evaluation signals

- transcript_class_counts.csv exists, contains the four class labels (known, ISM, NIC, NNC) and all three replicates
- Per-replicate class counts sum exactly to the total number of detected transcripts in that replicate
- Per-replicate classification is concordant across the three C2C12 dRNA replicates (known + ISM dominate, with reproducible NIC/NNC calls)
- annotateRNA.py outputs annotated BAM files plus TALON-compatible outputs and expanded QC CSVs for each genome
- Upstream mapping used the GTF-to-junction BED conversion and --splice-max 500000, so splice junctions match the annotation coordinate system

## Limitations

- Classification is only as complete as the reference GTF; unannotated splice sites drive NNC calls
- annotateRNA.py previously had a high memory footprint; Dogme mitigates it via 2-pass, per-chromosome processing, but very large annotations can still be costly
- The -CDNA flag is required for cDNA-specific behavior; using the dRNA defaults on cDNA data can misannotate reads
- minimap2's --splice-max 500000 caps intron length considered in spliced alignment, affecting detection of very long introns
