# autoencoder-shape-descriptor-training

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Trains an autoencoder neural network on binarized, major-axis-aligned, 128x128-resized segmented cell masks from MIRIAM to obtain learned low-dimensional shape latent vectors for single cells, replacing hand-crafted shape descriptors.

## When to use

Use when segmented single-cell masks from multiplexed tissue images (e.g., MIBI or multiplexed immunofluorescence) need a learned shape representation, because defined shape descriptors are insufficient for irregular columnar epithelial morphologies.

## When NOT to use

- The goal is intensity-based single-cell quantification (per-marker nucleus, membrane, cytoplasm measurements) rather than shape representation.
- Cells are too small or of such low quality that resizing to 128x128 and major-axis alignment would destroy meaningful morphology.
- You need segmentation itself (cell/nucleus/membrane delineation); this skill consumes already-segmented masks as its input.

## Inputs

- segmented cell masks (binary) from the MIRIAM segmentation pipeline, one per cell at each imaging position
- MIRIAM example dataset from the Coffey-Lab/MIRIAM repository (image stacks excluded; regenerated by the user via the linked Dropbox download)

## Outputs

- trained autoencoder shape-descriptor model
- CSV file of shape latent vectors for all segmented cells

## How to apply

Load segmented cell masks from the MIRIAM example dataset (github.com/Coffey-Lab/MIRIAM), binarize each mask, and rotate it so every cell's major axis is consistently aligned. Resize each aligned, binarized cell to a fixed 128x128 pixel matrix. Train the autoencoder on a random 20% subset of the cells using either the Matlab Deep Learning Toolbox or the Python Keras implementation provided in the repository. Pass all cells (including the 80% held out from training) through the trained encoder and save the resulting shape latent vectors for every cell to a CSV file. Downstream, latent vectors excluding training cells can be fed to t-SNE (Fig. 3B), as the authors chose an autoencoder specifically because methods using defined shape descriptors were inadequate.

## Evaluation signals

- Every aligned, binarized cell is exactly a 128x128 pixel matrix with its major axis in the same orientation before encoding.
- The training subset is a random 20% of cells; the remaining 80% are passed through the encoder without being used for weight updates.
- The latent-vector output contains one vector per segmented cell and is saved as a CSV.
- t-SNE computed on latent vectors excluding autoencoder-training cells should reproduce the shape-only embedding of Fig. 3B.
- Matlab and Python implementations should give largely similar results, per Supplemental Figure 6.

## Limitations

- The authors report that t-SNE shape analysis 'did not reveal any discernible cellular populations or clear patterns in marker expression (Supplemental Figure 5)', so shape latent space may not separate biologically meaningful populations.
- Training details/weights for the autoencoder cell-shape model are not provided in the article section, so exact hyperparameters must come from the repository tutorial.
- Example data in the repository omits image stacks (too large); users must regenerate them from the linked Dropbox download, and no version numbers are stated for the Matlab or Python implementations.
